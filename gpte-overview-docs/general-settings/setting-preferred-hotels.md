#### Add a hotel to the preferred hotel list <a href="#how-to-add-a-hotel-to-the-preferred-hotel-list" id="how-to-add-a-hotel-to-the-preferred-hotel-list"></a>

You can create your own list of hotel offers and display them as a separate group on the search results page to boost your sales or increase conversion rates.

1.  On the General settings menu, click Preferred hotels.

    ![](blob:https://gp-team.atlassian.net/1ec097fc-86d5-4b0a-8e5b-712688132471#media-blob-url=true\&id=d38a1d48-5c7a-4b3c-ab3d-212c0c69b96b\&collection=contentId-844890735\&contextId=1922255974\&width=207\&height=478\&alt=)
2.  On the Preferred hotels page, click Add. The following page appears:

    ![](blob:https://gp-team.atlassian.net/f707379f-bd2b-4d4a-9e5e-385a4f240cd1#media-blob-url=true\&id=cae0b1cd-6536-44ef-b5d8-d63224e9d0a1\&collection=contentId-844890735\&contextId=1922255974\&width=751\&height=495\&alt=)
3. On the Preferred hotel page, specify the following information:
   1. Country;
   2. City;
   3. Hotel;
   4. Configure sales channels.\
      ![spiral notepad](https://pf-emoji-service--cdn.us-east-1.prod.public.atl-paas.net/standard/ef8b0642-7523-4e13-9fd3-01b65648acf6/64x64/1f5d2.png) _See more information on configuring sales channels in the subsequent section._
4. Select the Ignore filter options for the preferred hotels check box if you want to display preferred hotels even if they do not fit the filters applied on search results page.
5. Specify the conditions of display for groups of preferred hotels:
   1. Click the entire group from all suppliers to display each hotel from one and the same group as preferred.
   2. Click only the specified hotel to display only selected hotel from the group.

{% hint style="success" %}
For more information on grouping hotels, please see Grouping hotels.
{% endhint %}

6. Click **Save**.

#### Setup sales channels for preferred hotels <a href="#setting-sales-channels-for-preferred-hotels" id="setting-sales-channels-for-preferred-hotels"></a>

**To set the sales channels** for a preferred hotel,

1.  On the preferred hotel page, click only for the following sales channels:

    ![](blob:https://gp-team.atlassian.net/33edbe63-65c6-43a6-8e08-0375bda5bcbd#media-blob-url=true\&id=3ec0af5f-97dd-44b8-b6b2-efc2b40ac41a\&collection=contentId-844890735\&contextId=1922255974\&width=760\&height=564\&alt=)
2. Click **Add**. The Sales channel window appears.
3.  In the **Sales channel** window, select the type of client from the drop-down and then select the check boxes opposite the required clients:

    ![](blob:https://gp-team.atlassian.net/a53c2a55-2560-429a-ab4a-391277cef76d#media-blob-url=true\&id=add0c6a0-f8f3-4e8f-b264-3c457804a379\&collection=contentId-844890735\&contextId=1922255974\&width=272\&height=203\&alt=)
4. Click **Save**. The preferred hotel will be displayed only for the selected clients.
