# !Product booking fields settings

{% hint style="warning" %}
This functionality is currently available via administration panel.
{% endhint %}

You can configure and make the list of booking fields more flexible by defining mandatory and optional fields.

1. On the general settings menu, click **Product booking fields settings**:

<figure><img src="../.gitbook/assets/product fields old.png" alt=""><figcaption></figcaption></figure>

2\. Select the product you would like to configure and click **Edit:**

3\. Choose **Mandatory**, **Optional** or **Disabled** option.

4\. Click **Save**.

{% hint style="success" %}
External suppliers have their own rules for required booking details. Supplier settings override the defaults and can be combined with the Tour Operator settings.
{% endhint %}
