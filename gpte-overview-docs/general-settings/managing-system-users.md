# Managing System Users

In GP Travel Enterprise, user profiles of your company and partner companies are stored in one single directory. This makes it easier to manage the staff structure of the companies as well as to search for a particular user.

#### Viewing the list of users registered in the system <a href="#viewing-the-list-of-users-registered-in-the-system" id="viewing-the-list-of-users-registered-in-the-system"></a>

To view the list of all users who have been registered in the system,

1. On the general settings menu, click All users.
2. The All Users page appears:

<figure><img src="../.gitbook/assets/mng usr 1.png" alt="" width="158"><figcaption></figcaption></figure>

Here you can search for a particular user, view a user's profile, modify it, or deactivate.

#### Searching for users registered in the system <a href="#searching-for-users-registered-in-the-system" id="searching-for-users-registered-in-the-system"></a>

To search for a particular user,

1. On the general settings menu, click All users.
2. The All users page appears.
3. Use the search form at the top of the page. Fill in the following search criteria:
   1. **Company:** select the name of the company where the user is registered.
   2. **Name:** enter the name of the user.
   3. **Role:** select the company type of user's employment (e.g. tour operator, travel agency, corporate client, etc.) and the user's role (e.g. director, supervisor, agent, etc.)
   4. **Login:** enter the login of the user.
4. Click Filter to initiate search process. The list of users will be contracted to those whose profiles suit your search criteria.

#### Viewing and editing profiles of system users  <a href="#viewing-and-editing-profiles-of-system-users" id="viewing-and-editing-profiles-of-system-users"></a>

To view and edit a profile of a user,

1. On the general settings menu, click All users. The All users page appears.
2. On the all users page, click the profile of the required user. User page appears:

<figure><img src="../.gitbook/assets/mng usr 2.png" alt=""><figcaption></figcaption></figure>

3. On the user page, make necessary corrections and click Save at the bottom of the page.

{% hint style="success" %}
You can deactivate any system user. Deactivated users are not deleted permanently, they are moves to archive. To deactivate a user, in the profile of a user, on the Information tab, switch off the Active toggle.
{% endhint %}
