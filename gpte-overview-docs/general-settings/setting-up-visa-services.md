# Setting up Visa Services

* [List of countries and visa service](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/1922255789/GPTE+Setting+up+Visa+Services#List-of-countries-and-visa-service)

![Warning](https://pf-emoji-service--cdn.us-east-1.prod.public.atl-paas.net/atlassian/productivityEmojis/exclamation-64px.png)**This functionality is currently available via administration panel.**

The system can provide information about visa regulations and visa services rendered by suppliers in certain countries.

#### List of countries and visa service <a href="#list-of-countries-and-visa-service" id="list-of-countries-and-visa-service"></a>

To open a list of countries and visa services,

1.  On the general settings menu, click Visa service.

    ![](blob:https://gp-team.atlassian.net/04825580-3eca-47d5-a798-6e56343a0748#media-blob-url=true\&id=31b18901-3b51-40d5-83c2-19dd6872e133\&collection=contentId-845545634\&contextId=1922255789\&width=239\&height=486\&alt=)
2. The Visa Service page appears. Click the tab with a required supplier.
3.  Click Modify opposite the required country to change the visa service availability.\
    The Visa Service for Country window appears:

    ![](blob:https://gp-team.atlassian.net/d870889b-6293-4263-b90e-7fb1fe0aad11#media-blob-url=true\&id=8d328992-b225-4227-b30e-0589574269ff\&collection=contentId-845545634\&contextId=1922255789\&width=220\&height=163\&alt=)
4. Select the type of visa support for each supplier. You can select among the following options:
   1. supported;
   2. not supported;
   3. visa free.
5. Click Save.
