# Generating API key

The most important part of API configuration is your “API Key”. This is the secure number that assures that only authorized developers can access your account via API.\
Please, do NOT share this key with nobody else, otherwise there’s the risk of unauthorized access to your application that might be very harmful!\
\
To generate API key,

1. On the Navigation bar, click **My** **Company** -> **Settings** tab.
2. On the Settings tab, click **Edit** to switch to editing mode.
3. Click **Generate**. Under the API-key label, the sequence of digits and letters appears:
4. 4\. Click **Save**.\
   5\. Give this API key for developers of external application that needs to be connected with your account.
