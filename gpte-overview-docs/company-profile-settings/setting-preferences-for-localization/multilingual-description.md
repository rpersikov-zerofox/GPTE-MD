# Multilingual Description

In the system, the pages containing text data are localized. It means that you can enter text information in different languages. It may be particularly useful if you offer services on the international level and have a network of clients across the globe. In this case using multilingual description will help you to successfully distribute your products and operate on the markets of different countries.

For example, you offer a self-operated tour on the Spanish speaking market and you would like to go to the English speaking market. You need to enter a tour description in both languages so that both Spanish and English speaking customers are able to get acquainted with the tour.\
To localize the tour description,

1. On the Navigation menu, click **Products** -> **Tours** tab.

2\. Click the required tour.\
3\. On the Information tab, select the language of your choice:

4\. Type a tour name in English & Spanish.\
5\. Click **Save**.\
6\. Repeat the above-mentioned steps for the other tabs (Description).\
\
Now the same tour (with the same conditions and rates) is offered both in English and Spanish depending on the language that is selected in the user settings. All users that work in the English version of the platform see the description of the tour in English. The users of the Spanish version of the platform will see it in Spanish. Descriptions of your own products in other languages are created in the same way.
