# Modifying Users

**Browsing Users**

After you have set up the profiles of the employees, you can view the list of created users organised in a list:

![users list.png](blob:https://gp-team.atlassian.net/407027db-4bd3-4525-bee4-3ba021a8f1ce#media-blob-url=true\&id=cc4d3db0-23a6-426c-b0af-36717a7a2d6e\&collection=contentId-1922236779\&contextId=1922236779\&width=1389\&height=137\&alt=users%20list.png)

On the **Users** tab, you can:

* Browse the users of your network.
* Search the users by name and by role.
* Add new users.
* Change user details and roles.
* Activate or inactivate users.
* Download the list of users to your computer.
  * To download the list of created users to your computer as an Excel-file, on the Users page, click![2024-10-28\_15-25-49.png](blob:https://gp-team.atlassian.net/5cb78bfb-dd7b-47be-8870-91eaff5bad58) The list of users will be downloaded to your computer in the XLS/XLSX format.
* Upload the list of users to company configuration.
  * To upload the list of users to company configuration, on the Users page, click ![2024-10-28\_15-27-01.png](blob:https://gp-team.atlassian.net/2f0799b9-f31d-4224-b782-2d2d1aae8ef7).

**Deactivating Users**

To restrict user's access to the system,

1. Open the profile of a required user.
2. Switch off **Active** toggle.

{% hint style="warning" %}
You can deactivate any user **except** for **Director**.
{% endhint %}

{% hint style="info" %}
User profiles are not deleted permanently from the system. All inactive profiles are stored in the archive. You can view the list of the archived users by clicking **Archive** on top of the user list and activate them if needed.
{% endhint %}
