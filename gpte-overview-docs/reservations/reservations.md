# Reservations

In GP Travel Enterprise all the reservations are stored in one directory. To view the list of reservations, click **Reservations** in the Navigation bar:

![2024-10-29\_22-47-45.png](blob:https://gp-team.atlassian.net/3288287e-e5df-42ec-98b3-eef55e492c73#media-blob-url=true\&id=0f93b70e-bf84-488b-9f0f-9ea692408ca3\&collection=contentId-1922253251\&contextId=1922253251\&width=995\&height=44\&alt=2024-10-29_22-47-45.png)

On the Reservations page, you can fully manage company’s reservations, specifically:

* Search for reservations;
* View and edit existing reservations;
* Assign and re-assign reservation managers;
* Receive/issue invoices for reservations.
