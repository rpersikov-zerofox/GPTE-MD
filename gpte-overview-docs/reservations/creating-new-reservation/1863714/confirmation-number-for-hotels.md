# Confirmation number for hotels

**Last Modified:** 2022-05-04T05:02:00.981Z\
**Version:** 2\
**Page ID:** 922124415

When booking hotels from suppliers with which you have direct contracts, the suppliers may send you the Hotel confirmation number, that should be saved to the order. To change the Hotel confirmation number:

{% stepper %}
{% step %}
### Open the reservation

Click on **Hotel Confirmation # field**.
{% endstep %}

{% step %}
### Enter the confirmation number

The Enter Hotel Confirmation # window will appear. Enter hotel confirmation number and press **Save**.
{% endstep %}
{% endstepper %}
