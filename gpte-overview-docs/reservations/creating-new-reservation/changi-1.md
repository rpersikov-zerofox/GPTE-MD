If room and meal types were set incorrectly when booking a self-operated hotel, you can change those options using manual correction.

{% stepper %}
{% step %}
### Open Manual correction

Click To manual correction. In the Manual correction window click **Yes**.
{% endstep %}

{% step %}
### Repair

Point to Repair button.
{% endstep %}

{% step %}
### Locate the field

Find the **Please specify hotel meal and room types** field.
{% endstep %}

{% step %}
### Update information

Change necessary information.
{% endstep %}

{% step %}
### Save

Click **OK**.
{% endstep %}
{% endstepper %}
