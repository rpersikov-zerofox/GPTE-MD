# Issuing e tickets

**Last Modified:** 2022-05-11T18:38:25.617Z\
**Version:** 3\
**Page ID:** 916914768

When booking a flight you should remember that a supplier does not guarantee the tourists that the booking price will remain unchanged. The final price is fixed when an e-ticket is issued. Thus, the booking made by a user initially has the Pre-booking status and should be confirmed by issuing an e-ticket within the period specified in the order.

{% hint style="warning" %}
If an e-ticket is not issued before the specified deadline and the automatic cancellation is enabled in the settings of the payment mode used for this booking, the preliminary booking will be canceled automatically and the order status will change to **Cancelled**.

If automatic cancellation is not enabled in the settings, the preliminary booking will not be canceled automatically. If the booking is not paid by the deadline, the supplier may impose a penalty.
{% endhint %}

To print out an e-ticket via the GP Travel Platform system, follow these steps:

{% stepper %}
{% step %}
### Open the order

On the Orders menu, click **Tour operator orders** and open the order you want to process.
{% endstep %}

{% step %}
### Check current status and price

Click the **Check Status** icon to obtain the up-to-date price and status of the order.

The modal window displays:

* booking ID (PNR)
* name of the tour leader
* up-to-date flight price
* order status
* available payment methods
{% endstep %}

{% step %}
### Choose action in the modal

Within the modal you can:

* Leave the order in its current Pre-booking status without issuing an e-ticket by clicking **Close**. The order will be saved with the new up-to-date price if the supplier’s price has changed.
* Pay and issue an e-ticket confirming the seat and the flight price by clicking **Issue e-ticket**.
{% endstep %}

{% step %}
### Issue e-ticket

Click **Issue e-ticket** to finalize the booking and fix the final price.
{% endstep %}
{% endstepper %}
