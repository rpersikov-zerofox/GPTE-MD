# Mass Receiving or Issuing Invoices for Reservations

Last Modified: 2022-05-04T05:06:54.706Z\
Version: 5

{% stepper %}
{% step %}
### Open reservations

On the Reservations menu, click **View reservations**.
{% endstep %}

{% step %}
### Select reservations

Select the reservations for which you want to receive/issue invoice.
{% endstep %}

{% step %}
### Open invoicing

Click **Receive / Issue invoice**. The Invoicing window appears.
{% endstep %}

{% step %}
### Choose action

In the Invoicing window, click the button of your choice — either get or issue an invoice.
{% endstep %}

{% step %}
### Export invoice

Click **Continue**, and then choose whether to save the invoice to PDF or to Excel. Click the respective button.
{% endstep %}
{% endstepper %}
