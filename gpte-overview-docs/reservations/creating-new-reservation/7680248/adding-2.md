According to business processes of working with bookings, sometimes there is a need to add to an existing reservation or remove from it early check-in and/or late check-out services for hotels added to the system by direct contracts in Inventory. When adding extra services for early check-in/late check-out to an existing reservation it is important to correct the total Netto price on the hotel as well, to include these extra charges in the total price.

{% hint style="info" %}
When you add or remove early check-in / late check-out services, ensure you update the reservation's total Netto price so it reflects the extra charges.
{% endhint %}

{% stepper %}
{% step %}
### Add or remove early check-in / late check-out

Click **To manual correction**. In the Manual correction window click **Yes**.
{% endstep %}

{% step %}
### Repair

Point to Repair button.
{% endstep %}

{% step %}
### Add extra service

Find extra service field in the pop-up. Press on the to add services.
{% endstep %}

{% step %}
### Confirm changes

After adding necessary extra services click **OK**.
{% endstep %}
{% endstepper %}
