# Issuing or Getting Flight Invoices

**Last Modified:** 2022-05-11T18:39:38.161Z\
**Version:** 3\
**Page ID:** 922124543

***

To issue or get an invoice, refer to the invoice window:

{% stepper %}
{% step %}
### Open the invoice/operations window

Click the respective button. The Operations window appears.
{% endstep %}

{% step %}
### Select services

In the window, select the services for which the invoice is issued/received, and click **Continue**.\
The Invoices and payments window appears with a link to the invoice.
{% endstep %}

{% step %}
### View and download the invoice

Click the link to view the invoice. The invoice opens in a separate window, where you can view and download it.
{% endstep %}
{% endstepper %}
