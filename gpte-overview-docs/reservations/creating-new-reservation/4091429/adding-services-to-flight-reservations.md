# Adding services to Flight reservations

**Last Modified:** 2022-05-04T05:04:14.709Z\
**Version:** 2\
**Page ID:** 922288291

You can book more services using GP Travel Enterprise and add them directly to the current reservation.

{% stepper %}
{% step %}
### In the Services group, point to **Add Service**
{% endstep %}

{% step %}
### Select the required service

The pop-up list of services appears. Click the required service — you will be redirected to the search form. Follow the steps as described in Search\&Book to finish the booking process.
{% endstep %}
{% endstepper %}
