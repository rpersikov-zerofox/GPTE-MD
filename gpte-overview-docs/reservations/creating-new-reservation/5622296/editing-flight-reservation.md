# Editing flight reservation

Last Modified: 2022-05-11T09:59:39.904Z\
Version: 5

***

You can view the information on the services included in the reservation and manage them. For that refer to the Services screen section on the Reservation tab.

In the Services section you can:

### E-ticket

E-ticket is a special form of a flight ticket that is offered to a customer instead of a conventional ticket slip and that is used to confirm a flight.

### Cancel

Click **Cancel** to cancel the reservation. A cancellation window appears. Click **Yes** to cancel the service.

{% hint style="warning" %}
If cancellation fees are to be paid, the sum of the fees and the payment method are displayed in the Cancellation window.
{% endhint %}

### Send E-mail

You can combine documents for booked orders (for example, vouchers and e-tickets) into a single package and send it to the user's e-mail specified during the booking process. Click **Send E-mail** and the Send e-mail window appears.

{% stepper %}
{% step %}
### Choose template and recipient

* Choose an e-mail template — the system will automatically generate the e-mail text.
* Choose the recipient.
* Change the e-mail subject if necessary.
{% endstep %}
{% endstepper %}

### To manual correction

Click **To manual correction**. In the Manual correction window click **Yes**.

* Point to the Repair button.
* Specify the required field(s) and change necessary information.
* Click **OK**.

### Book it again

Use this if you need to add the same service to another reservation or re-book the service if the confirmation has failed. Click **Book again** and the following window appears.

{% stepper %}
{% step %}
### Review imported information

The window imports information from the current service. Change the data if needed.
{% endstep %}

{% step %}
### Select target reservation

Select to which reservation the service is to be connected.
{% endstep %}

{% step %}
### Check availability and proceed

Click **Check availability**. If the same service is available, you will be redirected to the booking form (to the Offers tab). Follow the procedure described in Search\&Book to book the new service.
{% endstep %}
{% endstepper %}
