# Issuing or Getting Hotel Invoices

**Last Modified:** 2022-05-04T05:02:13.733Z\
**Version:** 3\
**Page ID:** 916685544

{% stepper %}
{% step %}
### Click the invoice button

To issue or get an invoice on the service, click the respective button. The Operations window appears.
{% endstep %}

{% step %}
### Select services and continue

In the window, select the services for which the invoice is issued/received, and click **Continue**. The Invoices and payments window appears with a link to the invoice.
{% endstep %}

{% step %}
### Open and download the invoice

Click the link to view the invoice. The invoice opens in a separate window, where you can view and download it.
{% endstep %}
{% endstepper %}
