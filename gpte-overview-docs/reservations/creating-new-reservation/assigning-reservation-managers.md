# Assigning Reservation Managers

**Last Modified:** 2022-05-04T05:06:39.578Z\
**Version:** 5\
**Page ID:** 844890711

***

To assign or re-assign a reservation manager, follow these steps:

{% stepper %}
{% step %}
### Open the Reservations view

On the Reservations menu, click **View reservations**.
{% endstep %}

{% step %}
### Select reservations

On the Reservations page, select the required reservations.
{% endstep %}

{% step %}
### Edit selected reservations

Click **Edit**.

{% hint style="info" %}
The "Change selected request" window appears.
{% endhint %}
{% endstep %}

{% step %}
### Choose managers

From the drop-downs, select the reservation manager and/or the service manager.
{% endstep %}

{% step %}
### Save

Click **Save**.
{% endstep %}
{% endstepper %}
