# Viewing and Editing Reservations

**Last Modified:** 2022-05-04T05:00:28.940Z\
**Version:** 8

To view a reservation’s details or edit a reservation, in the Reservation number column click the number of the required reservation.

The Reservation page appears. On the Reservation page you can:

* Edit the reservation.
* Check the reservation details and manage services.
* Issue or get an invoice.
* Add a service to the reservation.
* Download information about all reservations or only selected ones.

To download a list of reservations, click the “xls” icon and choose one of the options.
