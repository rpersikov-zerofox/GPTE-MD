## Searching for Reservations

To search for particular reservations, use the search form at the top of the page. The search form contains basic and additional search options.

### Basic search options

* Date/time: select the criterion of search (booking/check-out/modification/last ticketing, etc.) and specify its date and time.
* Number: select the number type by which you would like to search (the number of reservation, ref number, Channel manager number, etc.) and enter its value.
* Traveler: enter the name of the traveler for whom the reservation was made. If there are several travelers in the reservation, enter the name of the tour lead.

To expand the additional search options, click Additional parameters. The search form expands.

### Additional search parameters

The additional search parameters are grouped. Fill the appropriate group fields to narrow the results.

#### Service

In the Service group, specify any of the following criteria:

* Reservation name: specify the name of the reservation.
* Service type: select the service rendered in the reservation (transfer, accommodation, etc.).
* Country / city / region: select the location of service rendering.
* Service name: if looking for a particular service, enter its name (e.g., the name of the excursion – London Bridges).
* Service manager: enter the name of the company employee who is responsible for the service you search for.
* Status: select the reservation status (saved, pre-booking, completed, etc.).
* Manager: enter the name of a company employee who supervises the reservation you search for.
* Reservation status: select the required reservation status (new, in progress, completed, completed and revision is done, cancelled).
* Service team: service teams management is part of extended functionality. If you have access, select the required one from the drop-down.
* Apply filter to: select whether to apply filter to reservation or services.

#### Supplier

In the Supplier group, specify the following options:

* Supplier: select the required supplier.
* Channel manager: select required channel manager.
* Supplier payment: select the status of the supplier payment (invoiced, paid, waiting, etc.).
* Supplier penalty: select the status of the supplier penalty (cancelled w/o penalty, coming soon, matured, no penalty, not matured).
* Payment type: select the payment type – to the supplier or to the tour operator.
* Reservations with price remarks: if needed, select Reservations with price remarks checkbox.

#### Client

In the Client group, specify the following criteria:

* Client type: select the type of the client – legal or private.
* Client priority: select the client priority - VIP, high, normal, low.
* Client: enter the client name.
* Company: enter the name of the client company.
* Agent: enter the name of the agent who is responsible for the reservation.
* B2C: select the client website.
* Customer penalty: select the status of the customer penalty (cancelled w/o penalty, coming soon, matured, no penalty, not matured).
* Customer payment: select the status of the customer payment.
* Loyalty points: specify the range of the loyalty points a client possesses.
* Promo Code: enter a promo code.

#### Corporate policy

The Corporate policy group is relevant only for reservations made for corporate clients. Specify:

* Corporate policy: select whether the corporate policy is violated or not.
* Approval: select whether approval from a person in duty is required, is not required, approved, rejected or waiting for approval.
* Trip Organizer: enter the name of a trip organizer.
* Approval from: enter the name of the employee from whom the approval is awaited. Alternatively, select the Awaiting approval from me checkbox if you are searching for reservations you must approve.

{% hint style="info" %}
Please mind the distinction between reservations and services. One reservation may contain several services. That is why it is important to define whether you apply filters to reservation or to service. Otherwise, you can receive no search results.
{% endhint %}

### Performing the search

As soon as all the necessary search criteria are filled in, click Search to initiate the search process.

### Saving a search

You can save a combination of search criteria that you frequently use. Follow these steps:

{% stepper %}
{% step %}
### Fill the search form

Fill in the search form with the desired criteria.
{% endstep %}

{% step %}
### Click Save this search

Click "Save this search". The Save search window appears.
{% endstep %}

{% step %}
### Name and scope

Enter the name of the search, specify whether it is available only for you or for all users of the company, and click Save.
{% endstep %}

{% step %}
### Reuse saved searches

After saving is complete, select the required saved search from the drop-down so you don't have to fill in the search every time.
{% endstep %}
{% endstepper %}
