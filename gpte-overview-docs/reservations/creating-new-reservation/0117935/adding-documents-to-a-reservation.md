# Adding Documents to a Reservation

You can attach different documents to a reservation, e.g. hotel invitations, traveler’s passports and so on. To add documents:

{% stepper %}
{% step %}
Go to the Documents tab

Click **Upload**.
{% endstep %}

{% step %}
Add the document details

In the New documents window:

* Select the document type.
* Enter the validity period.
* Specify the document’s location on your PC or the Internet.

Click **Save**.
{% endstep %}
{% endstepper %}
