# Adding Documents to a Reservation

**Last Modified:** 2022-05-04T05:06:13.180Z\
**Version:** 6\
**Page ID:** 844890694

If needed, you can attach different documents to the reservation, e.g. hotel invitations, traveler’s passports and so on. To add documents:

{% stepper %}
{% step %}
### Go to the Documents tab

Click **Upload**.
{% endstep %}

{% step %}
### Add the document details

In the New documents window:

* Select the document type.
* Enter the validity period.
* Specify the document’s location on your PC or the Internet.

Click **Save**.
{% endstep %}
{% endstepper %}
