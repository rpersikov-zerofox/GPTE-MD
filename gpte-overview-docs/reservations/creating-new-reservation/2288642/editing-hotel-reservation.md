## Editing Hotel reservation

You can view the information on the services included in the reservation and manage them. For that refer to the Services screen section on the Reservation tab.

### Services section — overview

In the Services section you can:

* Download the voucher for the service.
* Modify the service data (date, tourists).
* Check service’s status (supplier confirmation).
* Send documents by e-mail.
* Book the same service again (add to another reservation or re-book).
* Appoint service teams and a manager.
* Cancel the service.

#### Voucher for the service

Click the Voucher button to download the voucher. The Get documents window appears. In the window, select whether to save a voucher as a PDF file or to send it to an e-mail. By default, the voucher will be sent to the e-mail specified on the Passengers/Tourists tab. You can enter any other e-mail. Click OK.

{% hint style="info" %}
For custom vouchers a block with manager and emergency service contact information was added. In case of urgent questions, contacts will always be at hand with a traveler.
{% endhint %}

#### Modify the service data

To modify the date of the service rendering or the information on tourists, click Modify. A Modification window appears.

{% stepper %}
{% step %}
### Modify service — step 1

Click Modify to open the Modification window.
{% endstep %}

{% step %}
### Modify service — step 2

Adjust the required data in the Modification window.
{% endstep %}

{% step %}
### Modify service — step 3

Click Check availability.
{% endstep %}

{% step %}
### Modify service — step 4

If modification is allowed, the confirmation window appears. Click Book to confirm the modification.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Please note that when modifying the service, the price can change. Read the message in the Modifications window carefully to avoid any inaccuracies.
{% endhint %}

#### Check service’s status

Certain services cannot be booked immediately and require supplier confirmation. To view the status of the service, click Check. The Check status window appears, where you can view the current service status received from the supplier.

#### Sent E-mail

You can combine documents for booked orders (for example, vouchers and e-tickets) into a single package and send it to the user's e-mail that was specified during the booking process. Click Sent E-mail and the Send e-mail window appears.

{% stepper %}
{% step %}
### Send e-mail — step 1

Choose an e-mail template; the system will automatically generate the e-mail text.
{% endstep %}

{% step %}
### Send e-mail — step 2

Choose the recipient. Change the e-mail subject if necessary.
{% endstep %}
{% endstepper %}

#### Book the service again

If you need to add the same service to another reservation or re-book the service if confirmation has failed, click Book again. The window that appears imports information from the current service.

{% stepper %}
{% step %}
### Book again — step 1

Change the data if needed.
{% endstep %}

{% step %}
### Book again — step 2

Select to which reservation the service is to be connected.
{% endstep %}

{% step %}
### Book again — step 3

Click Check availability. If the same service is available, you will be redirected to the booking form (Offers tab).
{% endstep %}

{% step %}
### Book again — step 4

Follow the procedure described in Search\&Book to complete the booking of the new service.
{% endstep %}
{% endstepper %}

#### Appoint service teams and a manager

To ascribe the service to a certain service team and to appoint a service manager, click the pen symbol opposite the Service team/manager label, select the required team/manager from the drop-down, and click Save. (For more details, see Extended management of reservations.)

#### Cancel

To cancel the reservation, click Cancel. A Cancellation window appears. Click Yes to cancel the service. If cancellation fees apply, the sum of the fees and the payment method are displayed in the Cancellation window.
