# Editing reservations

There are the following possibilities for editing the reservation:

{% stepper %}
{% step %}
### Add a remark to the reservation number

To add a remark to the reservation number, click the symbol opposite the reservation number. Enter the remark and click **Save**. (See group 1 in the figure below.)
{% endstep %}

{% step %}
### Ascribe the reservation to another manager

To ascribe the reservation to another manager, click the symbol opposite the manager name. A select manager window appears. Select the required person from the drop-down and click **Save**. (See group 2 in the figure below.)
{% endstep %}

{% step %}
### Change the reservation status

If you need to change the reservation status (for example if the supplier demands a revision of the reservation), click the symbol opposite the reservation status, select the required status from the drop-down (e.g. in progress, done), and click **Save**. (See group 3 in the figure below.)
{% endstep %}

{% step %}
### View the history of modifications

To view a history of modifications made to the reservation, click **History**. (See group 4 in the figure below.)

The history log appears, where you can see all the modifications, the time they were made and the user by whom they were made.
{% endstep %}

{% step %}
### Use the built-in chat

If you need to ask for or share certain information on the reservation, you can use a built-in chat. Click **Chat**. (See group 5 in the figure below.)

The Chat pop-up appears.
{% endstep %}

{% step %}
### Add and edit comments

For simplifying work with reservations after booking there is a possibility to add and edit comments.
{% endstep %}
{% endstepper %}

A booked tariff is displayed now in the reservation details page for booked products.
