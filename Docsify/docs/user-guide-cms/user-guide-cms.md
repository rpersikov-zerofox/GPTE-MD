# USER GUIDE. CMS

GPTE CMS provides users with the ability to support your brand by means of content. The functionality allows for controlling the system layout and home page element display and configuring them based on selected locale. Moreover, customization of blog and info pages, creation of unique selection of popular hotels and destinations, basic SEO support for these pages help achieve unique content marketing goals and establish clear communication with clients.

You can customize your content following the main navigation elements: **Collection types** and **Single types**. Each category contains the available collection and single content-types, which are created beforehand using the Content-Types Builder. Using these 2 categories, administrators can create, manage, and publish content.

![CMS Content Types](/assets/CMS-Content-Types.png)

## Filling up fields

To write or edit content:

1.  Access the Add/edit view of your collection or single type.
2.  Create your content, following the available field schema.
