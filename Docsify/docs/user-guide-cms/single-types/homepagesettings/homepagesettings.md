# HomePageSettings

In the "HomePageSettings" in **SearchFormBackgrounds** it is possible to download your pics for services which will be displayed on the search page of this service.

need setup correct image caption in cms: `hotel` `transfer` `activity` `flight` `package` `extraService` `conference_hall` `catering` `car` `insurance` `tour` `cruises`
