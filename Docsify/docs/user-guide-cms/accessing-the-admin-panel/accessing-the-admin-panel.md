# Accessing the admin panel

From the admin panel, you will be able to manage content types and create the related content.

To access the admin panel:

1.  Go to the URL of your Strapi application\'s admin panel - **CMS URL = website URL +/cms/admin.** Enter your credentials to log in.
2.  Click on the **Log in** button. You will be redirected to the homepage of the admin panel:

![Strapi Login](/assets/Strapi-Login.png)

Alternatively, you can go to the CMS via the **Settings** menu of your website under your credentials:

![Accessing the CMS within the System](/assets/Accessing-CMS-via-System.jpg)

## Setting up your administrator profile

If you are a new administrator, we recommend making sure your profile is all set, before diving into your Strapi application. From your administrator profile, you are able to modify user information, such as the name, username, email or password.

To do so:

1.  Click on your user name icon in the top right hand corner of the admin panel.
2.  In the drop-down menu, select **Profile**.
3.  Modify the information of your choice.

![Admin Profile Configuration](/assets/Admin-Profile-Configuration.jpg)

  ------------------------------------------------------------------------------------------------------------------------------
  User information        Instructions
  ----------------------- ------------------------------------------------------------------------------------------------------
  First name              Type your first name in the textbox.

  Last name               Type your last name in the textbox.

  Email                   Type your complete email address in the textbox.

  Username                Create a username (optional).

  Password                Enter a new password in the textbox. You can click on the eye icon for the password to be shown.

  Confirmation password   Re-type the new password in the textbox. You can click on the eye icon for the password to be shown.
  ------------------------------------------------------------------------------------------------------------------------------

4.  Press the **Save** button.
