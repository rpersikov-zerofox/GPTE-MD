# Trip Assistant

**Trip assistant** module - is ability for travelers to get their trip details and assistance from tour operator, who organizes the trip irrespective whether the booking was made directly from tour operator, or via any 3rd party travel agency.

The trip organizer can simply give a link to his web site with ability to enter booking number and last name - and to show the day-by-day trip plans. Note, that prices in this case are not shown because they can be different for different agencies.

![2024-12-19_11-19-11.jpg](/assets/2024-12-19_11-19-11.jpg)

Clicking on the link "Trip assistant" in menu of web site, an unlogged user is offered to enter Reservation Number and Last Name in the **Trip assistant** pop-up window:

![2024-12-19_11-19-37.jpg](/assets/2024-12-19_11-19-37.jpg)

After the details are entered, clicking on **Retrieve Booking** button displays trip plans - Itinerary tab - for the traveler: a) if this is direct booking via Tour Operator 1 level - then usual B2C order with prices, etc. is shown; b) if this is a booking via Travel Agency - then only Itinerary tab without prices, summary section on the right and buttons is shown.
