# Search of Complex Tours

To search for a complex tour,

1.  On the Home page, click **Complex Tours**. The Search form appears:

![image-20200924-110008.jpg](/assets/image-20200924-110008.jpg)

2.  On the search form, fill in the following basic search criteria:

- **Departure**: specify the departure location. You can either enter the location manually or click select from the list and select the required location from the drop-down.
- **Destination**: specify the destination location. You can either enter the location manually or click select from the list and select the required location from the drop-down.
- **Start date**: specify the period when the complex tour is to start.
- **Duration**: specify the complex tour duration.
- **Tourists**: specify the number of adult and child tourists. Please remember that for every child tourist you should additionally specify their age.

3.  On this stage you can either click **Search**to initiate search process or click **Additional search options** to specify more search criteria and get more precise results. Additional search options include:

- Only available: select the check box to see only offers that can be booked immediately and required no extra confirmation.
- Show detailed offers: select the check box in order to see the offers with the detailed information about them.
- Name: if you search for a particular complex tour, enter its name in the Name box.
- Supplier: select the preferred service supplier from the drop-down.

4.  Click **Search** to initiate search process.
