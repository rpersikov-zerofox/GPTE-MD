# Calculate

The Calculate option is available for numerical values. You can use it in order to calculate the date depending on specified data.

**Example**: You set check-in and check-out dates for a hotel component. The duration of the package is five days. Thus you can specify the check-in date for the hotel, and for the check-out date, select *calculate* and add the required value in the drop-down:
