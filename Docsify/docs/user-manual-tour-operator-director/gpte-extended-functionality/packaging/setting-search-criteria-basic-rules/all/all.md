# All

The All option is available for the limited number of categories and implies that all the possible options are implemented in the package.

**Example**: if you do not restrict hotel categories for accommodation component, select All opposite the Hotel category attribute:

![image-20200924-104933.jpg](/assets/image-20200924-104933.jpg)

Any attribute refers to search criteria a tourist should fill in in the search form (e.g. departure date, excursion point, arrival place, etc.) An attribute characterizes the first part of the value.
