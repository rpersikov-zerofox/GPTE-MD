# Setting Search criteria: Search form

In case the first part of the value is search_form, the search criteria of the component will adjust to the search criteria specified in the search form.

**Example:** You are to configure the flight component, specifically its departure and return dates. You do not want to restrict the flight component distribution by dates. Thus for the flight departure date you should select **search_form.start_date**, and for the flight return date - **search_form.end_date**. The dates of the flight component will adjust to those specified by a tourist in the search form.
