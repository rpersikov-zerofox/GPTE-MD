# Accommodation Itinerary

To add an accommodation service,

1.  Choose **Hotel** check-box. *Create hotel component*page appears:

![2024-11-14_11-41-55.jpg](/assets/2024-11-14_11-41-55.jpg)

2.  On the *Create hotel component* page, specify the entry code. It is filled in automatically by the system, but you can change the entry name manually for your convenience. The entry code is used for managing packaged components and is not displayed to tourists.
3.  Locate mouse pointer into the **Name** box and type the name of the service (hotel, flight, excursion, etc.) This name is displayed on search results page.
4.  **Day number**: choose which day this services is started from the drop-down list.
5.  Specify the way to include the component in the package. There are the following alternatives available:

- Mandatory service: the service cannot be removed from the package.
- Optional service: the service is additionally offered during the booking

1.  In the **City** window, select a city of package tour component(s).
2.  **Product:**locate mouse pointer into the box and start typing. After you type 3 characters the system will display the list of self-operated hotels. The items on the list are arranged by the alphabet. If you do not see the required item in the list. type some more characters - it may appear later.
3.  **Number of nights:** specify the number of nights for which the accommodation will be rendered.
4.  Set **tags**. By using tags you can manage access of certain groups of customers to products and rates. For example, by labeling certain products with the \"private\" tag you show them only to the customers that are interested in exclusive offers, while the standard offers with the \"public\" tag are available to all customers. You can create, edit and delete all tags, except for the default \"public\" tag. There are certain restrictions to the tag names:

- A tag name should consist of one or several words written in Latin characters.
- A tag name can include maximum 500 characters.
- If you use several tags, they should be separated with a comma.

1.  Click **Save**.
