# Transfer Itinerary

To create New transfer component,

1.  Go to the **Itinerary**tab, click **Create** and Choose **Transfer** check-box, click **Add**.
2.  *Create transfer component* page appears:

![2024-11-14_11-50-11.jpg](/assets/2024-11-14_11-50-11.jpg)

3.  On the *Create transfer component* page, fill in the following information:

- **Entry code**: It is filled in automatically by the system, but you can change the entry name manually for your convenience. The entry code is used for managing packaged components and is not displayed to tourists.
- **Name**: enter a transfer component name.
- **Day number**: choose which day this services is started from the drop-down list.
- Specify the way to include the component in the package. There are the following alternatives available: \* **Mandatory service**: the service cannot be removed from the package. \* **Optional service**: the service is additionally offered during the booking
- **Product:**locate mouse pointer into the box and start typing. After you type 3 characters the system will display the list of self-operated transfers. The items on the list are arranged by the alphabet. If you do not see the required item in the list. type some more characters - it may appear later.
- Set **tags**: By using tags you can manage access of certain groups of customers to products and rates. For example, by labeling certain products with the \"private\" tag you show them only to the customers that are interested in exclusive offers, while the standard offers with the \"public\" tag are available to all customers. You can create, edit and delete all tags, except for the default \"public\" tag. There are certain restrictions to the tag names: \* A tag name should consist of one or several words written in Latin characters. \* A tag name can include maximum 500 characters. \* If you use several tags, they should be separated with a comma.

1.  Click **Save**.
