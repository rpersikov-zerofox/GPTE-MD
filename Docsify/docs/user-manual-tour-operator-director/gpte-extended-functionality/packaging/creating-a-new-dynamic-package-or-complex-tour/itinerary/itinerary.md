# Itinerary

The final step of creating packaged products consists in specifying package components, i.e. the services included in the package. To add a package component,

1.  On the **Itinerary** tab of a Package Tour, click **Create**. The *New tour component* window appears:

![2024-11-18_10-10-53.jpg](/assets/2024-11-18_10-10-53.jpg)

2.  In the *New tour component*, click the appropriate button to choose the service you want to add. Let us consider component configuration of package components.
