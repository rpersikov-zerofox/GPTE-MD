# Search Dynamic package

To search for a dynamic package,

1.  On the Home page, click **Flight+Hotel**. The Search form appears:

![2024-11-18_12-09-52.jpg](/assets/2024-11-18_12-09-52.jpg)

2.  On the search form, fill in the following basic search criteria:

- **Departure location**: specify the departure point. You can either enter the location manually or click select from the list and select the required location from the drop-down.
- **Arrival location**: specify the destination location. You can either enter the location manually or click select from the list and select the required location from the drop-down.
- **Date**: specify the dynamic package start date.
- **Nights quantity**: specify the dynamic package duration in quantity of nights.
- **Guests:** specify the number of adult and child tourists. Please remember that for every child tourist you should additionally specify their age.

3.  On this stage you can either click **Search** to initiate search process or click **EXtra options** to specify more search criteria and get more precise results. Additional search options include:

- **Citizenship:**Select the tourist citizenship. The need to specify the citizenship is due to the fact that certain suppliers have limitations and price variations depending on the tourist citizenship. In case there are several tourists in the reservation, you can select the citizenship of a tour lead, and specify the citizenship of other tourists later, on the booking stage.
- **Show commission:** specify wether it is necessary to display a commission.

4.  Click **Search** to initiate search process.
