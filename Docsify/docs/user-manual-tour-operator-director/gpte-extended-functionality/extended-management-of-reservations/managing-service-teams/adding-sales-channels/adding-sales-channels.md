# Adding Sales channels

To add Sales channel,

1.  In the Sales channel section, click **Add**. The Sales channel window appears:

![image-20200924-114727.jpg](/assets/image-20200924-114727.jpg)

2.  Select one of the following sales channels:

- Agencies;
- Corporate clients;
- Tour operators;
- Direct sales.

3.  Select one or several clients in the table below.
4.  Select the main service manager.
5.  Click **Save**.
