# Recent Searches and Similar Hotels

There are a few more useful features you may use while working with GP Travel Enterprise system.

## Recent Searches

This feature is displayed in the **Your recent views** section under the description of a chosen hotel.

The system displays the hotels which you previously searched and navigated to:

![2024-11-25_15-42-58.jpg](/assets/2024-11-25_15-42-58.jpg)

With this option, you may:

- easily navigate to the previously searched hotels offers without repeating search requests.
- view and compare general description of the hotels basing on available information (ex. on prices / included services etc.) staying on the hotel description page.

To see recent searches in GP Booking Engine:

1.  Initiate the search of a hotel;
2.  select the hotel and click **Book** to see the hotel description page;
3.  at the bottom of the page review the recent views of previously searched hotels.
4.  to navigate to the hotel page from the recent views list, click on the offer price button. In order to scroll through all recent searches, click **\>** & **\<** arrows buttons:

![2024-11-25_15-43-15.jpg](/assets/2024-11-25_15-43-15.jpg)

## **Similar hotels**

*Similar hotels* is another important feature displayed under the description of a chosen hotel.

The system proposes similar hotels to the one you have chosen based on the matching criteria.

With this option, you may:

- find several hotel options for the clients
- easily find and replace hotels with no offers left.

To see similar hotels in GP Booking Engine:

1.  Initiate the search of a hotel;
2.  select the hotel and click **Book** to see the hotel description page;
3.  at the bottom of the page review the variants proposed:

![2024-11-25_16-19-10.jpg](/assets/2024-11-25_16-19-10.jpg)

1.  To navigate to the hotel page from the Similar hotels list, click on **View** button.
