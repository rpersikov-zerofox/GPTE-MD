# GIATA mappings

**This functionality is currently available via administration panel.**

In case one and the same hotel is provided by different suppliers, it can be displayed as several different offers. As it was mentioned previously, you can group such hotels manually and display them as one offer. Another alternative is to use GIATA mappings.

With GIATA mappings, such hotels are automatically grouped via GIATA. Each group is ascribe with a special code. The data on groups and their codes are automatically imported in GP Travel Enterprise. To obtain GIATA mappings, you should:

- Sign a direct contract with GIATA;
- Get the credentials for importing data in GP Travel Enterprise;
- Turn to GP technical support in order to request GIATA mappings feature;
- Pass the credentials required for importing data to GP technical support;
- In case GIATA mappings are available, you can access grouped hotels in the following way:

1.  On the General settings menu, click **List of hotels**.

![image-20200924-063100.jpg](/assets/image-20200924-063100.jpg)

2.  Search for the required city and/or hotel using the search form.

![image-20200924-064437.png](/assets/image-20200924-064437.png)

3.  In the GIATA code column, you can view the code ascribed to the group. It indicated that this hotel underwent GIATA mappings and is included into a certain group.

![image-20200924-064639.jpg](/assets/image-20200924-064639.jpg)

4.  In the Name column, click to view the list of hotels included in the group. The Hotel mappings window appears:

![image-20200924-065022.jpg](/assets/image-20200924-065022.jpg)
