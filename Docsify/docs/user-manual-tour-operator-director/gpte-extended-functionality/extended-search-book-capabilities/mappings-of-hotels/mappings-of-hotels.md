# Mappings of hotels

Hotels Mappings module is a plug-in to Hotels Content Management module that allows grouping the same hotels from different suppliers. This might be useful if you would like to combine them altogether and show the best price for hotel among multiple suppliers. With mappings of hotels you can:

- Use predefined automatic mappings (when hotel name and address are the same);
- Manually review and set grouping for the same hotels;
- Automatically recognize duplicating hotels during search&book and return identifier that this is the same hotel.

Note that you can either use Hotels Mapping Tool (if you want to do mappings by yourself) to order the mapping services from GP Solutions.
