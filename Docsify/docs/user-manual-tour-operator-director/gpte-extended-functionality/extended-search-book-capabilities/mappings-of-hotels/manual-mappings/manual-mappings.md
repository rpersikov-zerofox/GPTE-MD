# Manual mappings

**This functionality is currently available via administration panel.**

If provided by different suppliers, one and the same hotel can have different names and as a result be displayed as several different hotels. With GP Travel Enterprise you can group identical hotels from different suppliers and display them as one offer. For this, you should add appropriate hotels in one group and specify the rules of displaying hotels of this group in contract settings. For example, you have a direct contract with Hilton hotel in Prague. You also sell the same hotel as a part of your agreements with Hotelbeds, Tourico, GTA, and HotelsPro suppliers. In case grouping is not configured, this hotel will be displayed 5 times in different offers. To avoid that, you want all variants for this hotel to be displayed as one offer.

For that,

1.  On the General settings menu click **List of hotels**.

![image-20200924-063100.jpg](/assets/image-20200924-063100.jpg)

2.  Using the Search form at the top of the page, search for the required hotel (s):

![image-20200924-063213.png](/assets/image-20200924-063213.png)

3.  Click **Search**. The list of hotel results appears:

![image-20200924-063410.jpg](/assets/image-20200924-063410.jpg)

The Group number column is empty. It means that the hotels displayed do not make up a single group, thus they are displayed in search results as several different offers.

4.  To group hotels, select the required hotels:

![image-20200924-063607.jpg](/assets/image-20200924-063607.jpg)

5.  Click **Assign group**. The following window appears:

![image-20200924-063700.png](/assets/image-20200924-063700.png)

6.  In the group number window,

- Locate mouse pointer into the Group number box to specify the custom group number.
- Alternatively, click Get unique number to assign the group with the unique number generated by the system automatically.

In the Group number box you can use only numbers without spaces, dashes or other symbols.

7.  Click **Assign group**. The Group number column displays the unique group number. The group of hotels is now displayed as one single offer:

![image-20200924-064150.jpg](/assets/image-20200924-064150.jpg)
