# Voiding tickets

Flights Void allows you to void issued e-tickets directly from the system. Thus you can void a ticket within 24 hours from the booking time. To void a ticket,

1.  Click **Reservations**menu.
2.  Go to the required reservation.
3.  Click **Cancel** to void the flight reservation.

![2024-11-18_09-59-27.jpg](/assets/2024-11-18_09-59-27.jpg)

4.  In the Cancellation window, click **Confirm cancellation** to finish the voiding procedure.
