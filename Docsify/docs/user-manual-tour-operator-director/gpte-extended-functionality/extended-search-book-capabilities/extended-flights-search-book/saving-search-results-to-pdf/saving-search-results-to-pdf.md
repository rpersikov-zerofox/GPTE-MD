# Saving Search results to PDF

**This functionality is currently available via administration panel.**

In order to save the search results t a PDF-file and download it to your PC,

1.  Select the required offers you want to save or select all the offers.

![image-20200925-101727.jpg](/assets/image-20200925-101727.jpg)

2.  Click **(Save to PDF)**. The list of offers will be downloaded to your computer.
