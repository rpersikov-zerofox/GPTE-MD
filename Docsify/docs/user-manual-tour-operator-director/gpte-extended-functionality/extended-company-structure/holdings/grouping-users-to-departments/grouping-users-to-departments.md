# Grouping Users to Departments

After you have created the required number of departments, group company users corresponding to the department they work at.

To add a user to a department,

1.  Navigate to **My Company** menu → **Users**. The Users page appears.
2.  On the Users page, click the required user.
3.  On the User profile page select the required department from the **Department** drop-down, :

![2024-11-16_14-31-50.jpg](/assets/2024-11-16_14-31-50.jpg)

4.  Click **Save**. The user is added to a department.
