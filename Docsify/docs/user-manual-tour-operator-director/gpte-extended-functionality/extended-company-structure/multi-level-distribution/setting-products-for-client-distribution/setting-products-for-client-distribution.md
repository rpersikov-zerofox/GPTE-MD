# Setting Products for Client Distribution

**This functionality is currently available via administration panel.**

For every client company you should specify products and services that can be distributed within their contract. For that,

1.  Open the profile of the required client.
2.  Go to the **Contract** tab.
3.  On the **Products** tab, select the services that can be distributed via this client company:

![image-20200925-070218.jpg](/assets/image-20200925-070218.jpg)

4.  Click **Save** and proceed to the following tab.
