# VOIP Integration

**VOIP Integration** - is ability to connect with your IP telephony to capture client calls and automatically see information about them in the system.

GP Travel Enterprise can be used as ERP solution for Tour Operators and in this case it is extremely important to save time of employees and give as much visibility as possible.

One of the important actions is to quickly find client record when he calls to call center.

*For example:*

*Manager Anna Smith is getting inbound phone call from number +48-234-122-233. This is phone number of client Bill Jones. Based on information in client profile, the system should recognize this and immediately open client card on Anna's PC.*

Based on the phone number that is identified by IP telephony system finds corresponding account within the system. It can be one of the following:

1.  Private Client 1. Corporate Client (company or user) 2. Travel Agency (company or user) 3. Supplier (company or user)

The matching company /person is shown in *Incoming call* screen with a caller link that opens their profile.
