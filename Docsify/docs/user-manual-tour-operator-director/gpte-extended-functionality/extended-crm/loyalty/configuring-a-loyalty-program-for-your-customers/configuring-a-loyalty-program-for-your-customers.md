# Configuring a loyalty program for your customers

Cumulative loyalty programs are designed for the tourists making purchases through your B2C-website. To configure a program,

1.  On the Clients menu, click **Sales settings**.
2.  Go to the **Loyalty** tab.

![image-20200922-162920.jpg](/assets/image-20200922-162920.jpg)

3.  Click **Create**. The New loyalty program window appears.

4\. Enter the name of the program and configure loyalty point terms by using the configuration tree. Suppose you would like your tourists to earn 10% of the total price of your services in loyalty points. For this you only need to set loyalty points to 10% for all services.

![image-20200922-163034.jpg](/assets/image-20200922-163034.jpg)

If you want to set up complex rules for loyalty points accumulation, for example, rules varying with a supplier, type of service, or destination where it is rendered, you can configure them using the detailed term configuration tree. Loyalty points can be accumulated and calculated as a fixed amount or as a percentage of the total price. 5. Click **Save**.

Next you have to **connect the new loyalty program to the B2C-website**. For that,

1.  On the Clients menu, click **Sales settings** and go to the **B2C Settings** section.

![image-20200922-163316.png](/assets/image-20200922-163316.png)

2.  Select the respective В2С and go to the Contract tab.
3.  Click the **Loyalty** tab and choose a loyalty program to use on the B2C-website.

Loyalty points are accumulated in the currency that you specify in the B2C settings upon the connection of the loyalty program. If the currency you specify is different from the system currency, the system recalculates the loyalty points on the basis of the cross-rate between these currencies. From now on the tourists that book services via this website will earn points according to the terms of your loyalty program.
