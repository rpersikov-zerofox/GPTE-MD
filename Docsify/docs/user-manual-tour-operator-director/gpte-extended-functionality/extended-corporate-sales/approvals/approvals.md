# Approvals

**This functionality is currently available via administration panel.**

For corporate reservations, you can set the conditions for approval. Then in case a reservation is made for a corporate client, its status will not be set to *completed* unless the reservation is approved by a user with respective approval rights. Upon creating a reservation, a request for approval is sent to a user with approval rights:

![image-20200922-180732.jpg](/assets/image-20200922-180732.jpg)

As soon as the reservation is approved, its status will be set to **complete**.

To configure the approval conditions,

1.  On the Navigation menu, point to **Clients**, and click **Corporate clients**.
2.  Select a client of your choice and go to the **Approval** tab.
3.  On the Approval tab, click **Create**. The New Approval Schema window appears:

![image-20200922-181044.jpg](/assets/image-20200922-181044.jpg)

4.  In the New Approval Schema window, click\*\* Edit\*\*.
5.  Fill in the required information. Among others, pay attention to the following blocks:

- **User conditions**: In the **User conditions** block specify the users for whom the approval is needed.

![image-20220516-132155.png](/assets/image-20220516-132155.png)

- **Reservation conditions**: In the Reservation conditions block restrict the reservations for which the approval is needed.

![image-20220516-132221.png](/assets/image-20220516-132221.png)

- **Approval persons**: Appoint the person(s) who will have the rights to approve the reservations.

![image-20220516-132251.png](/assets/image-20220516-132251.png)

- **Allowable price increase**: Specify the amount by which the price for a service can be raised after approval.

![image-20220516-132317.png](/assets/image-20220516-132317.png)

6.  Click **Save**.
