# Configuring 3rd party contracts

**This functionality is currently available via administration panel.**

To configure 3rd party contracts,

1.  On the **Clients** menu, click **Corporate clients**.
2.  Click the required client profile.
3.  Go to the **Contract** tab and then to the **Tripartite agreements** tab.

![image-20200922-181338.jpg](/assets/image-20200922-181338.jpg)

4.  On the **Tripartite agreements** tab, click **Air tickets**section\*\* **and** Edit\*\* to upload an agreement for regulating air fares.
5.  Click **Upload**. The Configuration for airline tripartite agreement window appears:

![image-20200922-181504.jpg](/assets/image-20200922-181504.jpg)

6.  Click **Add**, browse to the XLS/XLSX file you want to upload, and click **Upload**.
7.  Click **Save**.

In order for the agreement to work properly, please turn to GP technical support to obtain a file template. Make sure to fill in the prices correctly.
