# Creating New Corporate Client

A corporate client profile is created by analogy with the agency/distributor profile. There are however certain distinctions, specifically: ability to add passports and bonus cards to employees profiles, as well as configure company offices for further quick search nearby them.

To create a new corporate client:

1.  On the Navigation menu, click **My Company** → **Corporate clients**.
2.  On the Corporate clients page, click **New Corporate Client**. The Create New Client page appears:

![2024-10-29_12-37-01.jpg](/assets/2024-10-29_12-37-01.jpg)

1.  On the Create new client page, fill in the information about the client company as it is described in . *The fields to be filled mandatory are marked with the asterisk (*)\*
2.  Click\*\* Save\*\*.
