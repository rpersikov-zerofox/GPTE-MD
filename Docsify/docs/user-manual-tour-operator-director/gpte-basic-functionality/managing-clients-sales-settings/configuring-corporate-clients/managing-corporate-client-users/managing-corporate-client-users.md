# Managing Corporate Client Users

When a corporate client profile is registered, the users of the client company can be created.

Note that to the contrary to Agencies, you may skip this step -- in this case you will be able to manage all reservations for this company by yourself and will fill in travelers manually at the moment of booking.

On the other hand it's more convenient to create user profiles for corporate clients in advance and give some of them Travel coordinator role -- these users will be able to view & create reservations for all employees; while other users can be created with Employee or External person role and they will be able only to search&book for themselves and view only own reservations in which they participate.

To create a new corporate client user,

1.  Navigate to **My Company** → **Corporate clients**.
2.  Click the corporate client for whom you want to configure the users, and then click **Users**.
3.  On the Users tab, click **Create**. *New User Profile* page appears:

![2024-10-29_09-46-18.jpg](/assets/2024-10-29_09-46-18.jpg)

4.  On the *New User Profile* page, fill in the information about the user. Among others, please pay attention to the following fields: 1. **Role:** from the Role drop-down, select the Director or Supervisor role to give the user maximum permissions. For more information on user roles, see [User roles](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/1922236707) . 2. **Log in:** the unique name that is used for logging in. The same log in cannot be assigned to different users within one company. At the same time you can create users with the same log in name in case they are registered in different companies. 3. **Password:** the password should contain at least three symbols (digits and Latin letters, both upper and lowercase) without spaces.
5.  Click **Save.**

You can create a client user without access in the system. In this case you will be able to use the information from the user profile in reservations, but the user himself will not be able to log in the system.

**Adding Passport Data**

**This functionality is currently available via administration panel.** You can add passport data to the user profile of a corporate client. Then while booking a service for a corporate client, you will not have to ask for the passport data of the employees every time, and just export them to the reservation request.

To add a passport data to a corporate client user profile,

1.  In the user profile, to which you would like to attach passport data, click Passport.
2.  On the Passport tab, click Create. The Passport window appears:

![2024-11-18_16-24-16.jpg](/assets/2024-11-18_16-24-16.jpg)

3.  Click **Save** and then **Close**.

As a result passport data of a client are automatically imported in reservations. When booking a service - for example, a flight - for a corporate client user, on the Passengers page you have to enter the name of the user only - the other data needed for reservation will be imported automatically.

**Adding Bonus Cards**

**This functionality is currently available via administration panel.** If a corporate client user has a bonus card, you can add it to his/her profile. Then while booking a service for a corporate client, you will not have to enter the bonus card info manually - you could just select it and the information will be imported.

To add a bonus card,

1.  In the user profile, to which you would like to attach a bonus card, click **Bonus Card**.
2.  On the Bonus card tab, click **Create**. The Bonus Card window appears:

![image-20201005-052507.jpg](/assets/image-20201005-052507.jpg)

3.  Select the service for which you add a card - flight or train. 1. For Avia bonus cards, select the airline; 2. For railway bonus cards, select the card type.
4.  Enter bonus card number.
5.  Click **Save**.

As a result added bonus card is added to a corporate user profile and you can simply select it from the drop-down, without entering the information manually.

**Managing Client Offices** You can add offices to corporate client\'s profile. Configuring corporate offices helps you make your work in the system more convenient. If you have corporate offices configured, while searching services you may also search by the name of the office. For example, while booking a service for a corporate client, you can search by the office. All you will need to do is select the name of the office.

To add a new office to a profile of a corporate client,

1.  On the Navigation menu, click **My Company → Corporate clients**.
2.  Select the corporate client of your choice and go to the **Offices** tab.
3.  On the Offices tab, click Create. The New Office window appears:

![image-20201005-052934.png](/assets/image-20201005-052934.png)

1.  In the New Office window, specify the following information: 1. **Name:** type the name of the office. 2. **Country, city:** select the items of your choice from the drop-downs. 3. **Type:** select whether the office is located in a city or near an airport. 4. **Address:** type the address of the office. The information you type will be used for displaying the office on the map. 5. **Latitude, Longitude:** the data are required to correctly display your office on the map. Use Google maps to find out the exact location of your office. The way to do that is described below under the Defining Office Location on the Map title. 6. **Contacts:** specify the contact person and their phone number, fax, and working hours of the office. 7. **Comments:** leave any additional information o the office.
2.  Click **Save**.

**Defining Office Location on the Map**

**This functionality is currently available via administration panel.** To find the exact location of your office on the map,

1.  Open Google maps.
2.  Enter your office address in the search form and press Enter.
3.  On the map, click on the building of your office. At the bottom of the map the coordinates of the office appear:
