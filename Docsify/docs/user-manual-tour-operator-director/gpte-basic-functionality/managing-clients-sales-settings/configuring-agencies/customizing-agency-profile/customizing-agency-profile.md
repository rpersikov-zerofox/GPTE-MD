# Customizing Agency Profile

**This functionality is currently available via administration panel.**

On the Settings tab, you can personalize the look of the system so that it complies with the brand and identity of a client agency. You can also configure the localization preferences, links with external applications, and notifications. feel of an agency,

1.  On the Navigation menu, point to **Clients**, and click **Agencies/Distributors**.
2.  Click the client company you would like to configure. The Client page appears.
3.  Click **Settings** and then click **Edit**.
4.  On the Settings tab, specify the information, according to the principles, described in the [Specifying Company Profile Settings](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/1922236805) .
5.  Click **Save**.
