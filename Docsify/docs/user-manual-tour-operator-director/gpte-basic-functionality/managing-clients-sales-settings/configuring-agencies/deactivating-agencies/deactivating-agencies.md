# Deactivating Agencies

To restrict the access to the system for a particular agency/distributor,

1.  Open the profile of a required agency.
2.  Switch off the **Active** toggle.
3.  Click **Save.**

Agency profiles are not deleted permanently from the system. All inactive profiles are stored in the archive. You can view the list of the archived agencies by clicking Archive on top of the clients list and activate them if needed.
