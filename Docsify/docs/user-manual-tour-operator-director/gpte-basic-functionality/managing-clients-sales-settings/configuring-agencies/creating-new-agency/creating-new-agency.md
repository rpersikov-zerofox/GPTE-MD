# Creating New Agency

To register a new Agency please, do the following:

1.  On the Navigation menu click **My Company** →\*\*Agencies/Distributors\*\*.
2.  On the Agencies/Distributors tab, click **New Agency**. Create New Agency page appears.
3.  On the Create new client page, fill in the information about the client company as it is described in [Configuring Information about the Company](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/1922236498). *The fields to be filled mandatory are marked with the asterisk (*)\*
4.  Click **Save**.
