# Browsing Private Clients

To search for private clients,

1.  On the Navigation menu, click **My Company** → **Private clients**.
2.  Use the search form at the top of the page:

![2024-10-29_15-42-03.jpg](/assets/2024-10-29_15-42-03.jpg)

1.  In the search form, specify the search criteria of your choice: 1. **Country:** select the country specified in the private client\'s profile upon creating. 2. **City:** select the city specified in the private client\'s profile upon creating. 3. **Name:** enter the name of the user you search for. 4. **Membership level:** select whether the user you search for is registered in the system, or has guest access. 5. **Date of registration:** specify the date when the user was registered in the system. 6. **Number of reservations:** specify the range of the reservations conducted for the user you search for. 7. **Current balance:** specify the financial balance of the user. 8. **E-mail:** specify the e-mail address.
2.  Click **Filter**. The list of private client users will be updated to those fitting your search requirements.

Granted with the director or supervisor roles, you can view the list of all private clients, who make reservations via your internal agency or your client agencies.

To view the list of private clients,

1.  On the Navigation bar, click My Company → Private clients.
2.  The Clients page appears where the list of private clients is displayed. In the list you will find the main information on private clients, including: 1. Name&Surname 2. B2C 3. Manager 4. Stage 5. Country&city 6. Phone number 7. E-mail 8. Registration date 9. First and last reservation dates 10. Membership level 11. Expiration date 12. Number of reservations 13. Current balance 14. Status.

![2024-10-29_15-45-08.png](/assets/2024-10-29_15-45-08.png)

To view the detailed information about a client, click the client of your choice. The client information is displayed on several tabs:

- **Information:** displays general information about a client.
- **Documents:** displays passport data of a client.
- **Reservations:** stores the information about a private client\'s reservations.
- **Communications**: list of types of communication held with the client
- **Settings**: E-mail preferences and tags management.
