# Creating New Private Client

To create a new private client,

1.  On the Navigation menu, click **My Company** → **Private clients**.
2.  On the Private clients page, click **New Client Profile**. The New Client page appears:

![2024-10-29_15-24-02.jpg](/assets/2024-10-29_15-24-02.jpg)

1.  On the Info tab, fill in the following data: 1. **First name:** enter the first name of the client as it is stated in the government issued ID. 2. **Last name:** enter the last name of the client as it is stated in the government issued ID. 3. **E-mail:** enter the e-mail address to which the notifications concerning reservations will be sent. 4. **Language:** select the language in which the system will operate for a certain client. 5. **Additional information:** travel preferences, disability etc.
2.  Click\*\* Save.\*\*

After you click Save, the member ID is ascribed to the client, which will be user forinternal identification of the client in the system.

To generate a new password for a user to be able to log in the system, please consult the Web Sales Settings section.

**Adding Passport Data** You can save passport information to the profile of a of a private client and further use it when creating reservations.

To save the passport data,

1.  On the Navigation bar, click My Company → Private clients.
2.  Select the client for whom you want to add passport data, and click their name in the Name&Surname column. The Client page appears.
3.  Go to the Documents tab, and click Create Passport. The Passport window appears:

![2024-10-29_15-28-27.png](/assets/2024-10-29_15-28-27.png)

1.  Fill in the required information.
2.  Click **Save**.

As a result passport data of a client are automatically imported in reservations. When booking a service - for example, a flight - for a corporate client user, on the Passengers page you have to enter the name of the user only - the other data needed for reservation will be imported automatically.
