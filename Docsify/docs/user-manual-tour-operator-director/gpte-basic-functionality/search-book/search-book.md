# Search & Book

The Search & Book module allows you to find and reserve travel products from suppliers through the GP Travel Enterprise platform. Book accommodation, flights, transfers, activities, and other travel services for your clients.

## Overview

Search & Book provides access to:

- Hotels and accommodation
- Flights
- Trains
- Transfers and ground transportation
- Tours and activities
- Car rentals
- Visas
- Travel insurance

## Booking Workflow

The standard booking process follows these steps:

### 1. Search for Products

Search for available travel products using your specified criteria. The platform displays real-time availability information.

The system supports two booking types based on supplier availability:

- **Instant Booking** - Services with confirmed availability can be booked immediately
- **Request Booking** - Services require supplier confirmation before the booking is finalized

### 2. Review Search Results

Browse available options and compare prices, features, and supplier terms. Refine your search criteria if needed.

### 3. Select and Book

Choose the product that meets your requirements and proceed with the booking.

### 4. Receive Confirmation

Wait for booking confirmation from the supplier. Instant bookings confirm automatically, while request bookings require manual supplier approval.

### 5. Create Reservation

Once confirmed, the system creates a reservation record with all booking details. You can then:

- Modify reservation details
- Add additional products to the reservation
- Generate vouchers and documentation
- Process payments and invoicing

**Note:** Reservations created directly through supplier systems (outside of GP Travel Enterprise) will not appear in the platform.

## Pricing Calculation

The system calculates final prices using this sequence:

1. **Supplier Base Price** - Starting price from the supplier
2. **Markup Application** - Your configured markup percentage or amount
3. **Contract Discounts** - Discounts defined in self-operated product contracts (applied in tariff order)
4. **Promotional Discounts** - Additional discounts from Discounts & Promotions module (calculated from post-contract amount)
5. **VAT/Taxes** - Applicable taxes based on your configuration

## Common Operations

Typical Search & Book tasks include:

- Creating new bookings for single or multiple products
- Combining multiple services in one reservation
- Searching and viewing existing reservations
- Modifying active reservations
- Canceling bookings
- Generating vouchers and confirmation documents

## Search Methods

Access travel products using two search methods:

### 1. Search Form

Use the standard search interface to find products by destination, dates, and other criteria.

[Learn more about the Search Form](search-form/search-form.md)

### 2. Reservation Request

Create a booking request for a specific client type:

- Private clients (individual travelers)
- Corporate clients (business travel)
- Tour agencies (wholesale bookings)

[Learn more about Creating Reservation Requests](creating-a-new-reservation-request/creating-a-new-reservation-request.md)
