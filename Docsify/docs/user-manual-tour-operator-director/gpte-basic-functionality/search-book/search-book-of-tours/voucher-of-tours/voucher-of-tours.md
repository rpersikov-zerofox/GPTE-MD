# Voucher of Tours

After you click **Book**, a confirmation pop-up appears:

![2024-11-28_16-13-40.jpg](/assets/2024-11-28_16-13-40.jpg)

Click **OK.**A page with the created reservation is displayed:

![2024-11-28_16-16-05.jpg](/assets/2024-11-28_16-16-05.jpg)

At this point you can work with the reservation (manage and edit it).

**To get a voucher**:

![2024-11-28_16-18-50.jpg](/assets/2024-11-28_16-18-50.jpg)

- to download it in PDF format, either click **Voucher** in the reservation summary or click **Voucher** button at a particular service;
- to send it to E-mail, click **Voucher** button at a particular service, select "Send to E-mail" option → click OK.

For more information please see [Reservations](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/916685544).
