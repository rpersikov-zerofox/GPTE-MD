# Booking of Tours

After you select a tour offer on the Search results page, the Tour booking page appears:

![2024-11-28_16-06-18.jpg](/assets/2024-11-28_16-06-18.jpg)

![2024-11-28_16-06-50.jpg](/assets/2024-11-28_16-06-50.jpg)

## In the *Guests* section,

1.  Specify tourist data, which include:

- First Name;
- Lasy Name;
- Date of Birth.

1.  You can optionally leave a comment for a service supplier.
2.  Click **Next Step** to proceed to the Payment section.

In the *Payment section* select a payment method; read cancellation terms and select the respective check box.

Click **Book**.
