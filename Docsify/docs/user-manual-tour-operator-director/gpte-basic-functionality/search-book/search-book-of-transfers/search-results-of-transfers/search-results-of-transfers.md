# Search results Of Transfers

Transfer search results are arranged in the following way:

![2024-11-05_12-25-58.jpg](/assets/2024-11-05_12-25-58.jpg)

- To see the detailed information on the offers, click **Show.**Available offers are expanded:

![2024-11-05_12-27-00.jpg](/assets/2024-11-05_12-27-00.jpg)

- To book an offer, choose the suitable one and click on the button with price at the chosen offer. You will proceed to the booking step.

**"Save offers" functionality is currently available via administration panel.**

- To save the offers and view them offline, you can download the list of offers to your PC as a PDF-file. To do so, select the required offers, or select the checkbox in the table header to select all the offers (See the figure below) and click (Save to PDF).

![image-20200922-124542.jpg](/assets/image-20200922-124542.jpg)

- Save search results to PDF window appears. In he window, select whether to save all the offers or only the selected offers, and click **Save**.
