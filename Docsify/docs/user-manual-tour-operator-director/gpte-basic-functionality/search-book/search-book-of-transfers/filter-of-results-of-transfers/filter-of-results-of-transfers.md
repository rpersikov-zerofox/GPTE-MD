# Filter of results of Transfers

Sometimes the number of found offers is quite redundant. To leave off the unnecessary offers, you can use the filter of results. To apply filters, refer to the panel to the left of search results:

![2024-11-05_11-50-21.jpg](/assets/2024-11-05_11-50-21.jpg)

There are the following filters available:

- **Price**: move the sliders across the scale or indicate the required range manually to limit the permissible price range.
- **Supplier**: select the preferred supplier.
- **Name**: if you search for a particular transfer, you can enter its name manually.
- **Type**: select the preferred type of transfer: private or shared.
- **Cancellation policy**: select appropriate option(s) related to cancellation policy applied.
- **Escort language**: select the language of the escort.

Search results are automatically updated corresponding to the filters applied.
