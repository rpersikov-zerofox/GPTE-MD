# Booking Of Transfers

Booking of transfers consists of three steps:

## **Offers**

On the *Offers* stage, confirm the selection of the offer, and click **Book**. Besides, you can view additional information on the offer, which includes:

- Transfer service information -- full description of a transfer and services included.
- Price -- the detailed information on price.
- Cancellation policy -- cancellation terms and conditions.

![2024-11-05_12-38-10.jpg](/assets/2024-11-05_12-38-10.jpg)

![2024-11-05_12-38-54.jpg](/assets/2024-11-05_12-38-54.jpg)

In case you want to change the search option and search for a transfer on a different date or for a different number of tourists, click **Change** in the Transfer reservation group:

![2024-11-05_12-41-35.png](/assets/2024-11-05_12-41-35.png)

The following search form appears:

![2024-11-05_12-43-14.jpg](/assets/2024-11-05_12-43-14.jpg)

In the form, enter the new search options and click **Search**. In case an offer that suits new search parameters is found, the reservation will be automatically updated.

## **Passengers**

On the *Passengers* stage,

1.  Specify tourist data, which include:

- First and Last name;
- Date of Birth;
- Citizenship;
- Contact E-mail and phone number:

![2024-11-05_12-45-05.jpg](/assets/2024-11-05_12-45-05.jpg)

2.  Specify the pick-up and drop-off points:

![2024-11-05_12-47-21.jpg](/assets/2024-11-05_12-47-21.jpg)

For Transfers bookings if client knows terminal to which he arrives or departs - now it can be specified. This is optional, so if this information is not available - it can be just skipped. But for the suppliers who accept terminal information - this will be transferred via API.

![2024-11-05_12-49-49.png](/assets/2024-11-05_12-49-49.png)

1.  Specify return transfer if needed, selecting **Add return transfer** check box and clicking **Check Availability** button in the appeared pop-up:

![2024-11-05_12-50-47.jpg](/assets/2024-11-05_12-50-47.jpg)

After selecting the return transfer, it is added to the corresponding section:

![2024-11-05_12-51-29.jpg](/assets/2024-11-05_12-51-29.jpg)

1.  You can leave a comment to the supplier in the Comment field. It is possible to enter additional requests there (for example inquire about the availability of a safety seat for children):

![2024-12-20_17-40-18.jpg](/assets/2024-12-20_17-40-18.jpg)

1.  Click **Next step** to proceed to the Confirmation stage.

## **Confirmation**

On the Confirmation stage:

Specify the payment method selecting a preferred one from the available options.

Select the terms of use check boxes and click\*\* Book\*\*:

![2024-11-05_12-56-28.png](/assets/2024-11-05_12-56-28.png)
