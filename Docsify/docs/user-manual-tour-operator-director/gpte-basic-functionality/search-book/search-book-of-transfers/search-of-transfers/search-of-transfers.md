# Search of Transfers

To search for a transfer,

1.  Click the transfer tab to expand the search form. The transfer search form appears:

![2024-11-05_11-35-52.jpg](/assets/2024-11-05_11-35-52.jpg)

2.  In the search form, specify the following information:

- **Departure location:** for the departure you should specify the pick-up location.
- **Arrival location:** for the arrival you should specify the drop-off location.
- **Date:** specify the transfer rendering date.
- **Time:** specify the preferred time of the transfer.
- **Passengers:** specify the number of adult and child passengers. For children, additional Age drop-downs appear corresponding to the number of children in the reservation. Thus for every child tourist you should specify their age.

3.  On this stage you can click **Search** to initiate search process. Alternatively if you want to get more precise results, click **Extra options** to expand the additional search criteria:

![2024-11-05_11-36-08.jpg](/assets/2024-11-05_11-36-08.jpg)

4.  Specify the following additional search criteria:

- **Transfer type**: select the check box of your choice depending on the preferred type of transfer: private or shared.
- Specify suppliers type(s) to be considered while searching flights offers selecting **Internal suppliers** and/or **External suppliers**check boxes.
- **Supplier**: select the preferred supplier from the drop-down.
- **Citizenship:** Select the tourist citizenship. The need to specify the citizenship is due to the fact that certain suppliers have limitations and price variations depending on the tourist citizenship. In case there are several tourists in the reservation, you can select the citizenship of a tour lead, and specify the citizenship of other tourists later, on the booking stage.
- **Promo code**: Enter a promo code if you have one.
- Select\*\* Show commission \*\*check box to display agency commission values at prices.

5.  Click **Search**.

## Search by Map

When you search for transfers - you have ability not only select hotel or airport or station, but also pick-up any location on the map

![2024-12-20_17-37-37.jpg](/assets/2024-12-20_17-37-37.jpg)

## Search by IATA code

If you know IATA code of departure/arrival airport and need transfer from there - you can search not only by city or airport name, but also by this code. This will help to avoid mistakes when ordering transfers (with ability to double check that airport corresponds the one to which flight arrives or departs).
