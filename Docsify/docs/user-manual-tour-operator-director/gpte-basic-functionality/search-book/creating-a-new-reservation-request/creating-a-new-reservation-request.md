# Creating a New Reservation Request

In GP Travel Enterprise there are several ways to create a new reservation. They are:

1.  The General way to create a new reservation request is, 1.1. On the Homepage, click **New reservation request**:

![2024-10-29_22-53-08.jpg](/assets/2024-10-29_22-53-08.jpg)

1.2. Specify the required information in the New reservation request window:

![2024-10-29_23-03-52.jpg](/assets/2024-10-29_23-03-52.jpg)

1.  Or you can create New reservation request by another way: 2.1. On the Reservations page, click **New reservation request:**

![2024-10-29_22-55-34.jpg](/assets/2024-10-29_22-55-34.jpg)

2.2. Specify the required information in the New reservation request window:

![2024-10-29_23-03-52.jpg](/assets/2024-10-29_23-03-52.jpg)

1.  In case you want to create a new reservation request for a Tour Agency, 3.1. In the New reservation request form select **Tour Agency**option:

![2024-10-29_23-11-22.jpg](/assets/2024-10-29_23-11-22.jpg)

3.2. Select the *required agency*: locate mouse pointer into the box. The system will display the list of suggestions agencies. The items on the list are arranged by the alphabet. 3.3. Choose *the required agent:*locate mouse pointer into the box. The system will display the list of suggested agents. New agent can be created at this step. 3.4. Select a *client* from the list OR create new client profile.

3.5. Enter request *title* and *details.*

1.  In case you want to create a new reservation request for a corporate client, 4.1. In the New reservation request form select **Corporate Client**option,

![2024-10-29_23-14-02.jpg](/assets/2024-10-29_23-14-02.jpg)

4.2. Select the *required company*: locate mouse pointer into the box. The system will display the list of suggestions clients. The items on the list are arranged by the alphabet. 4.3. Enter request *title* and *details.*

1.  If you want to create a reservation request for a particular client - **Private Client**, on the **Clients** menu, in the New reservation request form select **Private Client**option and fill the form by analogy with previous steps.

![2024-11-04_10-53-21.jpg](/assets/2024-11-04_10-53-21.jpg)
