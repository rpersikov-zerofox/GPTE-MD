# Creating a Reservation for Particular Client Types

Another method of searching for products implies searching products for a particular client.

To do so, you can first select the client for whom to search travel services and then conduct the search procedure.

![2024-11-04_10-53-21.jpg](/assets/2024-11-04_10-53-21.jpg)

**Search for Agencies**

To search for travel products,

1.  On **My Company → Agencies / Distributors** select the agency client for whom you would like to create a reservation. On the Reservations sub-tab, click **Search&Book**:

![2024-11-04_10-56-59.jpg](/assets/2024-11-04_10-56-59.jpg)

1.  In the appeared pop-up enter a name and select an agent or whom you would like to create a reservation. Click **Continue**:

![2024-11-04_10-58-25.jpg](/assets/2024-11-04_10-58-25.jpg)

1.  The Home page appears with the search form for the indicated agent:

![2024-11-04_11-01-31.jpg](/assets/2024-11-04_11-01-31.jpg)

1.  Fill in the search form the way it is described in the Search form.

**Search for Corporate Clients**

To search for travel products,

1.  On **My Company → Corporate Clients** select the client for whom you would like to create a reservation. On the Reservations sub-tab, click **Search&Book**:

![2024-11-04_11-04-25.jpg](/assets/2024-11-04_11-04-25.jpg)

1.  The Home page appears with the search form for the indicated corporate client:

![2024-11-04_11-07-14.jpg](/assets/2024-11-04_11-07-14.jpg)

1.  Fill in the search form the way it is described in the Search form.

**Search for Private Clients**

To search for travel products,

1.  On **My Company → Private Clients** select the client for whom you would like to create a reservation. On the Reservations sub-tab, click **Search&Book**:

![2024-11-04_11-12-33.jpg](/assets/2024-11-04_11-12-33.jpg)

1.  The Home page appears with the search form for the indicated private client:

![2024-11-04_11-13-25.jpg](/assets/2024-11-04_11-13-25.jpg)

1.  Fill in the search form the way it is described in the Search form.

Another way to search and book for a particular client is to use "Select agent / client" functionality at the search form:

- in the search form click **Select agent / client**;
- in the appeared **Search and book for** pop-up select a type of client, for which the search is executed, and enter its name → click **Continue**;
- proceed with filling the search form according to the request.
