# Search & Book of [Trains]()

To search for train tickets,

1.  Click the Trains tab to expand the search form. The search form appears:

![image-20201013-095815.jpg](/assets/image-20201013-095815.jpg)

1.  Fill in the following search parameters:

- **Departure**: specify the departure location. You can either type the location manually or click select from the list in order to select the required country and city from the respective drop-downs.
- **Arrival**: specify the arrival location. Enter the arrival location manually or click select from the list and select the required location from the drop-down.
- **Date**: specify the required date. Click and click the date in the calendar. Alternatively, locate mouse pointer into the box and type the date manually.
- **Time**: specify the appropriate time of departure.
- **Passengers**: specify the number of passengers for whom the reservation is carried out.

2.  On this stage you can either click Search to initiate search process or click **Additional search options** to expand the form of search criteria. This can help you get more precise results:

![image-20201013-100013.png](/assets/image-20201013-100013.png)

3.  Specify the additional search parameters, which include:

- **Show detailed offers**: select the check box in order to get the extended information on the offer in search results.
- **Reservation system**: select the preferred reservation system from the drop-down.
- **Show net prices from suppliers**: select the check box in order to see not only client price, but also a supplier price. Please pay attention that you should have respective rights to be able to use this option (director or supervisor).

4.  Click **Search** to initiate search process.
