# Seat selection

You can select seats either on the search results page or on the next stage - booking. In case you prefer to select the seat on the search results page,

1.  Click in the coach column opposite the coach you want to book a seat in. The Detailed info window appears:

![image-20201106-093512.jpg](/assets/image-20201106-093512.jpg)

2.  You can choose a seat either by schema or by parameters. Depending on the mode you choose, go the required tab.
3.  When selecting by schema, click **Book** opposite the required table entry.

![image-20201211-120500.jpg](/assets/image-20201211-120500.jpg)

4.  When selecting by parameters, fill in the preferred seat characteristics and click **Book**.

![image-20201211-120503.jpg](/assets/image-20201211-120503.jpg)
