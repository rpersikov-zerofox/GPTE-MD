# Search & Book of Trains

**This functionality is currently available via administration panel.**

Search&Book of trains consists of the following steps:

1.  [Search](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/968228995)
2.  [Filter of Results](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/970096743)
3.  [Search Results](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/970096743)
4.  [Seat Selection](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/965607708)
5.  [Booking](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/967966887)
6.  [Voucher](https://gp-team.atlassian.net/wiki/spaces/GPTEUG/pages/968229072)
