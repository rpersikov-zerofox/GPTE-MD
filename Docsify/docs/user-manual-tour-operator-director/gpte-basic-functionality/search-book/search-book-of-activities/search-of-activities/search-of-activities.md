# Search of Activities

To search for activities,

1.  On the Home page, in the search form, click the **Activities** tab to expand the search form. The Activities search form appears:

![2024-11-05_14-51-26.jpg](/assets/2024-11-05_14-51-26.jpg)

1.  On the search form, there are basic and additional search options. First, fill in the basic search options, which include:

- **Destination**: You can select the required destination form the list of destinations. For that, select the required location from the Destination drop-down.
- **Dates range**: specify the service rendering dates. To specify the date, select the required dates range in the calendar.
- **Guests** specify the number of adult and child passengers. For children, additional Age drop-downs appear corresponding to the number of children in the reservation. Thus for every child tourist you should specify their age. Please keep in mind that different suppliers have different standards for the maximal number of tourists in one reservation.

1.  If you want to restrict search results to more accurate offers, you can specify additional search criteria. For that, click **Extra options**. The search form expands:

![2024-11-05_14-59-15.jpg](/assets/2024-11-05_14-59-15.jpg)

1.  Specify the following search options:

- **Type:** specify the type of activity - shared or private.
- Specify suppliers type(s) to be considered while searching activities offers selecting **Internal suppliers** and/or **External suppliers**check boxes
- **Supplier**: select a preferred service supplier.
- **Citizenship:** Select the tourist citizenship. The need to specify the citizenship is due to the fact that certain suppliers have limitations and price variations depending on the tourist citizenship. In case there are several tourists in the reservation, you can select the citizenship of a tour lead, and specify the citizenship of other tourists later, on the booking stage.
- **Promo code**: Enter a promo code if you have one.
- Select\*\* Show commission \*\*check box to display agency commission values at prices.

1.  Click **Search** to initiate search process.
