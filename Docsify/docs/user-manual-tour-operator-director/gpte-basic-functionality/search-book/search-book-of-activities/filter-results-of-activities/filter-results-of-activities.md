# Filter results of Activities

After the search process is finished, the page with search results appears.

![2024-11-05_15-05-46.jpg](/assets/2024-11-05_15-05-46.jpg)

However sometimes the number of found offers may be quite redundant. In order to filter the results and leave only those that suit your criteria completely, you can use the Filter form on the left part of the screen:

![2024-11-05_15-06-54.jpg](/assets/2024-11-05_15-06-54.jpg)

You can apply the following filters:

- **Price**: move the sliders across the scale or indicate the required range manually to limit the permissible price range.
- **Supplier**: select the preferred supplier.
- **Date**: select a concrete date from the range.
- **Name**: enter the required activity name.
- **Short Description**: enter the required activity short description.
- **Type**: select the preferred type of activity: private or shared.
- **Start Time**: select a concrete start time from the available options.
- **Themes**: select the preferred activity theme.
- **Category**: select the preferred excursion category.
