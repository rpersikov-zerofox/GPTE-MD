# Flight Voucher

To finish the reservation process, you need to have an e-ticket.

To receive an e-ticket,

1.  Click E-ticket. The E-ticket pop-up appears:

![2024-11-04_16-31-31.jpg](/assets/2024-11-04_16-31-31.jpg)

1.  In the pop-up, select either to download an e-ticket as a PDF-file or to send to an e-mail and click OK. As soon as you conduct all the checks and receive an e-ticket, set the reservation status to complete.

![2024-11-04_16-34-09.jpg](/assets/2024-11-04_16-34-09.jpg)
