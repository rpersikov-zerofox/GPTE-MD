# Booking flights

The next two steps of booking flights are:

- filling passenger information;
- confirming reservation.

**Filling passenger information**

1.  Fill in the information about passengers (or a user with already existing information in the system can be selected above):

![2024-11-04_14-16-02.jpg](/assets/2024-11-04_14-16-02.jpg)

2.  As soon as all the necessary information is specified, click Next step.

**Confirming reservation**

1.  Select the payment method and required terms and conditions of the selected offer, checking corresponding check boxes:

![2024-11-04_16-23-00.jpg](/assets/2024-11-04_16-23-00.jpg)

1.  Click **Book** to confirm reservation.
