# Saving offers

**This functionality is currently available via administration panel.**

There are two methods of saving: saving offers to PDF and saving offers to basket.

**To save the charter offers to PDF**,

1.  In case you need to select only some of the offers, select the required ones:

![image-20200920-191338.png](/assets/image-20200920-191338.png)

2.  Alternatively, click the check box to select all the offers:

![image-20200920-191433.jpg](/assets/image-20200920-191433.jpg)

3.  Click Save to PDF. The list of selected offers will be downloaded to your computer as a PDF-file.

In case you have selected an offer and want to consider it later, you can save the offer to a basket.

**To save an offer to a basket,**

1.  Opposite the required offer, click Basket. Add offer to basket window appears:

![image-20200922-212643.jpg](/assets/image-20200922-212643.jpg)

2.  In the add offer to basket window, select the required basket and click Close. *To add a new basket, clickadd to a new basket, enter the name of the basket and clickSave.*
3.  All the created baskets are displayed on the Home page. To view the saved offers, click the required basket:

![image-20200922-212910.png](/assets/image-20200922-212910.png)

4.  Inside the basket, the saved offers are displayed:

![image-20200922-214113.jpg](/assets/image-20200922-214113.jpg)
