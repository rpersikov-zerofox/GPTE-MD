# Filtering Search Results

After you click Search, the page with the search results appears. Sometimes the number of found offers can be redundant. In such cases filtering search results may be quite useful.

To filter search results, refer to the panel to the left of the search results page:

![2024-11-04_15-48-01.jpg](/assets/2024-11-04_15-48-01.jpg)

1.  In the form, specify the suitable filtering criteria, which include: 1. **Price:** move the sliders across the scale or indicate the required range manually to limit the permissible price range. 2. **Flight number:** in case you search for a particular flight, enter the flight number. 3. **Stops:** specify the search basing on presence of stops (direct flight or with stop(s)). 4. **Duration**: specify the flight duration, moving the runner across the scale. 5. **Departure/arrival time:** move the pointers along the bars to set the preferred departure and arrival time\*\*.\*\* 6. **Airports:** specify the preferred airports both for the departure and arrival flights. In case you want to return to the same airport, select the **Depart/return same airports** check box. 7. **Transfer airports:** in case you allow stopovers, select preferred transfer airports. 8. **Airlines:** specify the preferred airline(s). 9. **Baggage**: specify wether baggage should be included or not. 10. **Tariff**: specify the preferred tariff(s). 11. **Refundable**: specify wether the flight cost is refundable or not.
2.  The results are automatically updated according to the specified sorting criteria.
