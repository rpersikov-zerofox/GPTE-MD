# Simple Search

There are two methods of searching flights: simple search and search by time-table. Search by time-table is the part of extended functionality. For more information on the topic, please see . In this section we will dwell on simple search procedure.

To search for flights,

1.  On the Home page, in the Search form, click Flights.
2.  The flights search form appears:

![2024-11-04_15-03-31.jpg](/assets/2024-11-04_15-03-31.jpg)

![2024-11-04_15-19-22.png](/assets/2024-11-04_15-19-22.png)

1.  Specify the flight type: 1. Round trip 2. One way 3. Multi city

**Search for roundtrip flights**

1.  For the roundtrip flights, specify the following basic search options: 1. Specify the **Departure location** of the flight. *You can both type the location manually or clickSelect from the listin order to select the required country, city and airport from the respective drop-downs.* 2. Specify the **Arrival location**. *You can both type the location manually or clickSelect from the list*\* in order to select the required country, city and airport from the respective drop-downs.\* 3. **Departure and Return dates:** specify the departure and return dates range. *To specify the dates range, click Dates field and select the required dates in the calendar.* 4. **Passengers:** specify the number of passengers and indicate the number of adult and child tourists in the reservation request. *For every child, you should also specify their age in the special drop-down that appears at the Children drop-down:*

![2024-11-04_15-31-34.jpg](/assets/2024-11-04_15-31-34.jpg)

2.  Click **Search** to initiate search process. Alternatively, if you want to get more precise results, click Extra options to expand the additional search parameters. The additional search options include: 1. **Search by price & Search by schedule:** you can search flights by price or by schedule. Click the required option. 2. **Class:** with the class selection you can leave out unsuitable offers and choose to display only offers of certain classes (e.g. only economy class). 3. **Airline:** select the preferred airline(s). 4. **Only with baggage, Only refundable, Only direct:** select the required check box(es) depending on search request. 5. Specify suppliers type(s) to be considered while searching flights offers selecting **Internal suppliers** and/or **External suppliers**check boxes. 6. **Supplier**: Select a preferred flights supplier. 7. **Citizenship:** Select the tourist citizenship. The need to specify the citizenship is due to the fact that certain suppliers have limitations and price variations depending on the tourist citizenship. In case there are several tourists in the reservation, you can select the citizenship of a tour lead, and specify the citizenship of other tourists later, on the booking stage. 8. **Promo code**: Enter a promo code if you have one. 9. Select\*\* Show commission \*\*check box to display agency commission values at prices.
3.  Click Search to initiate search process.

**Search for oneway flights** The procedure of searching for oneway flights coincides with that of the roundtrip, except that you do not have to specify the return date. Please, see **Search for roundtrip flights** for information about filling the search form.

**Search for multi-city flights** With the multi-city flights, you can create a combined flight with the combination of several destinations.

To search for a multi-city flight,

1.  On the search form, click Multi city. The search form appears:

![2024-11-04_15-36-57.jpg](/assets/2024-11-04_15-36-57.jpg)

1.  Set the required number of flights: 1. To add another flight, click Add route. 2. To remove a flight, click .
2.  For every flight, specify the following information: 1. **Departure location:** specify the flight departure point. 2. **Arrival location:** specify the flight arrival point. 3. **Departure date:** specify the departure date. 4. **Passengers:** specify the number of passengers.
3.  Repeat the procedure for every flight in the combination.
4.  On this stage you can either click Search to initiate search process or if you want to get more precise results, click Extra options. The search form expands. For more information on filling in additional search parameters, please see **Search for roundtrip flights**.

**Search by schedule by booking class** There is a possibility to search flight by schedule by booking class. Such enhancement is available only for Sabre supplier. It is permitted to choose one booking class within one root.

1.  Find Search by schedule oprion in additional search options on search form.
2.  See various booking classes on the search results.
