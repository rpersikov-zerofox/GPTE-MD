# Filter of results

After the search process is finished, the page with search results appears. However sometimes the number of found offers may be quite redundant. In order to filter the results and leave only those that suit your criteria completely, you can use the Filter form on the left part of the screen:

![2024-11-04_12-48-41.jpg](/assets/2024-11-04_12-48-41.jpg)

You can apply the following filters:

- **Price:** move the sliders across the scale or indicate the required range manually to limit the permissible price range.
- **Suppliers:** select the preferred suppliers.
- **Name**: enter the required hotel name.
- **Cancellation policy:** select the preferred cancellation conditions.
- **Start rating**: select the preferred hotel category rating.
- **Accommodation Type**: select the preferred accommodation type.
- **Meal type:** select the preferred meal types.
- **Special offer**: specify whether to leave only special offers or display all the search results.
- **Locations:**specify the preferred area where a hotel is located (Airport, CityCenter, CityLimits, OutsideCity, RailwayStation).
- **District:** specify the city district where you want the hotel to be located (e.g. Greenwich, Kensington, etc.).
- **Distance to Center**: select the preferred distance to center in km.
- **Hotel Chain:** specify the preferred hotel chain.
- **Hotel Amenities:** select the required hotel amenities.
- **Popular Amenities:** select the required amenities from the popular ones.
- **Classification:** select the required classification types (e.g. Art deco, Business, Eco hotel, Family, etc.).
- **Room Type:** select the required room type.

Search results are automatically updated.
