# Search

To search for accommodation services,

1.  On the Home page, in the search form, click **Hotels** tab:

![2024-11-04_12-01-04.jpg](/assets/2024-11-04_12-01-04.jpg)

1.  On the search form, there are basic and additional search options. First, fill in the basic search options, which include: 1. **Destination:** 1. You can select the required destination form the list of popular destinations. For that, click Destination drop-down and select the needed value from the list. 2. To enter the required destination manually, enter the required destination in the Destination field and select the needed value from found drop-down values. 2. **Check-in, check-out:** 1. You can specify check-in and check-out dates. 2. To specify the dates, select the required dates range in the calendar. 3. **Rooms and Guests:** Select the required number of rooms to book specifying the number of tourists for each room. It is possible to specify quests quantity by Age category (Adults & Children) for each room. 1. For child tourists, you should also specify their age. When you specify the number of children in the reservation, the additional Children Ages boxes appear for each child:

![2024-11-04_12-14-54.png](/assets/2024-11-04_12-14-54.png)

2.  If you want to restrict search results to more accurate offers, you can fill in additional search criteria. For that, click **Extra options**. The search form expands:

![2024-11-04_12-19-50.jpg](/assets/2024-11-04_12-19-50.jpg)

1.  Fill in the following search options: 1. **Star rating:** Specify the hotel category selecting one of available values from the *Star rating* dropdown. 2. **Meal type:** Specify the preferred meal types selecting one or more values from *Meal type* dropdown. 3. Select\*\* Only available\*\* check box in order to see only offers that can be booked immediately and require no additional supplier confirmation. 4. Specify suppliers type(s) to be considered while searching accommodation offers selecting **Internal suppliers** and/or **External suppliers**check boxes. 5. **Supplier**: Select a preferred accommodation supplier. 6. **Citizenship:** Select the tourist citizenship. The need to specify the citizenship is due to the fact that certain suppliers have limitations and price variations depending on the tourist citizenship. In case there are several tourists in the reservation, you can select the citizenship of a tour lead, and specify the citizenship of other tourists later, on the booking stage. 7. **Promo code**: Enter a promo code if you have one. 8. Select\*\* Show commission \*\*check box to display agency commission values at prices.
2.  Click **Search** to initiate search process.
