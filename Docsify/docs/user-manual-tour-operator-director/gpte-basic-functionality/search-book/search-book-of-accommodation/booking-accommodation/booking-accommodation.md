# Booking Accommodation

Booking accommodation consists of 3 steps:

1.  Choosing the required offer
2.  Specifying information about tourists
3.  Selecting payment method and confirming reservation

**Choosing the required offer** After you click Book on the Search results page, the Hotel description page appears:

![2024-11-04_14-02-21.jpg](/assets/2024-11-04_14-02-21.jpg)

On the Hotel description page, select the required offer and click on its price to proceed with specifying guests information.

**Specifying information about tourists** On the Guests page, enter the information about tourists:

![2024-11-04_14-11-38.jpg](/assets/2024-11-04_14-11-38.jpg)

You can leave a comment for accommodation provider (optional):

![2024-11-04_14-12-59.png](/assets/2024-11-04_14-12-59.png)

Select accommodation add-ons if needed:

![2024-11-04_14-14-08.jpg](/assets/2024-11-04_14-14-08.jpg)

Click **Next step**.

**Selecting Payment method**

Specify the preferred payment method among available options:

![2024-11-04_14-16-02.jpg](/assets/2024-11-04_14-16-02.jpg)

Read the terms and conditions of the selected offer and select corresponding check boxes.

Click **Book** to confirm reservation.
