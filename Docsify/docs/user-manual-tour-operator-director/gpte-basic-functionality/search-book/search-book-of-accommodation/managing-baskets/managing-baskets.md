# Managing Baskets

**This functionality is currently available via administration panel.**

You can save offers into basket and view, edit and book them later. To save an order to a basket, opposite the required offer, click . The Add offer to basket window appears:

![image-20201003-210630.jpg](/assets/image-20201003-210630.jpg)

In the window, select one of the existing baskets or click **Add to a new basket** to create a new one, then enter its name and select the check box opposite the new basket. Click **Close**. After you saved an order to a basket, on the Home page, new tabs appear compliant to the created baskets:

![image-20201003-210716.jpg](/assets/image-20201003-210716.jpg)

To view the contents of the basket, click the required tab (e.g. New Basket 1). The Basket page appears, which contains saved offers. To return to the search results, click the **Main window** tab.
