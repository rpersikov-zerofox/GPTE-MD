# Search & Book of Visas

**This functionality is currently available via administration panel.**

Search&Book of visa services consists of the following steps:

## Search

On the search form,

1.  Go to the **Visa** tab. The search form expands.
2.  Fill in the required search criteria: 1. **Country:** specify the country of entering. 2. **Entry date and departure date:** specify the entry date and the departure date. In this case the duration will be automatically calculated. 3. **Duration:** Alternatively specify the entry date and the duration. In this case there is no need to specify the departure date. 4. **Tourists:** specify the number of adults and children. For every child tourist additionally specify their age in the additional form.
3.  On this stage you can click **search** to initiate search process. Alternatively if you want to get more precise results, click **Additional search options** to fill in additional search criteria, which include: 1. **Entry type:** select the required entry type, e.g. single, multiple. 2. **Supplier:** select the preferred service supplier. 3. **Country of residence:** select the tourist\'s country of residence. The selection is required while certain suppliers may have service restrictions depending on the tourist\'s country of residence. 4. **Net prices from suppliers:** select the check box in order to see not only client prices but the supplier prices. 5. **Detailed offers:** select the check box in order to see offers with their detailed descriptions.
4.  Click **Search** to initiate search process.

## Results

On the search results page, choose the required offer and click **Book**.

To make the process easier, use the following prompts:

- Click to view the detailed information on the offer.
- Click **Expand All** to see the list of all offers available for a certain visa service.

![image-20201019-130626.png](/assets/image-20201019-130626.png)

## Booking

On this stage, specify the information in the following 3 sections:

- Offers
- Applicants
- Reservations

**Offers** In the Offers section, select the required offer and click **Continue**.

![image-20201019-131149.png](/assets/image-20201019-131149.png)

**Applicants** In the Applicants section, specify the information about the tourists:

![image-20201019-131313.png](/assets/image-20201019-131313.png)

**Reservation** In the reservation section,

1.  Optionally leave a comment for a service supplier.
2.  Select preferred payment method.
3.  Read the cancellation terms and select the respective check box.
4.  Click **Book** to confirm your booking.

![image-20201019-131417.jpg](/assets/image-20201019-131417.jpg)
