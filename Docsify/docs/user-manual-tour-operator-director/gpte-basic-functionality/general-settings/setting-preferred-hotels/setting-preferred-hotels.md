# Setting Preferred Hotels

**This functionality is currently available via administration panel.**

## How to add a hotel to the preferred hotel list

You can create your own list of hotel offers and display them as a separate group on the search results page to boost your sales or increase conversion rates.

**To add a hotel** to the preferred hotels list,

1.  On the General settings menu, click Preferred hotels.

![Screenshot_2.png](/assets/Screenshot_2.png)

2.  On the Preferred hotels page, click Add. The following page appears:

![image-20200921-193606.png](/assets/image-20200921-193606.png)

3.  On the Preferred hotel page, specify the following information: 1. Country; 2. City; 3. Hotel; 4. Configure sales channels. *See more information on configuring sales channels in the subsequent section.*
4.  Select the Ignore filter options for the preferred hotels check box if you want to display preferred hotels even if they do not fit the filters applied on search results page.
5.  Specify the conditions of display for groups of preferred hotels: 1. Click the entire group from all suppliers to display each hotel from one and the same group as preferred. 2. Click only the specified hotel to display only selected hotel from the group. *For more information on grouping hotels, please see Grouping hotels.*

- Click Save.

## Setting Sales Channels for Preferred Hotels

**To set the sales channels** for a preferred hotel,

1.  On the Preferred hotel page, click only for the following sales channels:

![image-20200921-193809.png](/assets/image-20200921-193809.png)

2.  Click Add. The Sales channel window appears.
3.  In the Sales channel window, select the type of client from the drop-down and then select the check boxes opposite the required clients:

![image-20200921-194533.jpg](/assets/image-20200921-194533.jpg)

4.  Click Save. The preferred hotel will be displayed only for the selected clients.
