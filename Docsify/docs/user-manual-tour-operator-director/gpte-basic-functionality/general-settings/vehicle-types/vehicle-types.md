# Vehicle Types

In order to be able to indicate types of transfers for vehicles categorization, it's necessary to have **Vehicle types** that can be configured in advance and then used for further needs (Microbus (9), Bus (51), Standard car).

To create a new vehicle type,

1.  navigate to **General Settings** menu → **Vehicle types.***Vehicle types* list page is displayed:

![2024-11-27_12-07-51.png](/assets/2024-11-27_12-07-51.png)

![2024-11-27_12-07-51.png](/assets/2024-11-27_12-07-51.png)

1.  Click **Create**, *Create new vehicle type* page appears:

![2024-11-27_12-08-48.jpg](/assets/2024-11-27_12-08-48.jpg)

1.  Fill in the following mandatory information: 1. **Name**: enter vehicle name. 2. **Max capacity**: indicate maximum quantity of passengers supported by the vehicle type.
2.  Click **Save**. New vehicle type appears in the list and can be used where needed (ex. for creation of Transfer catalogue categories):

![2024-11-27_12-27-13.png](/assets/2024-11-27_12-27-13.png)

To edit the vehicle type information, on the *Vehicle types* list page click on the name link of the vehicle; on the appeared vehicle type page edit Name and/or Capacity information and click **Save**.

To inactivate a vehicle type, open it and switch **Active** toggle off, click **Save**. To activate the vehicle type again, switch **Inactive** toggle on, click **Save**. To view inactive vehicle types, on the list page switch **Active** toggle off:

![2024-11-27_12-35-37.png](/assets/2024-11-27_12-35-37.png)
