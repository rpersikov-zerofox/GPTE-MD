# Locations

## Viewing List of Countries and Cities

To view the list of all the countries and cities available in the system for search,

1.  On the General settings menu click Locations:

![2024-11-09_23-19-58.png](/assets/2024-11-09_23-19-58.png)

1.  The **Locations** page with Countries, Cities and Location Points tabs appears, where you can view the destinations available in the system.

![2024-11-09_23-20-11.jpg](/assets/2024-11-09_23-20-11.jpg)
