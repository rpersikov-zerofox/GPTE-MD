# Product booking fields settings

**This functionality is currently available via administration panel.**

For flexibility to be able to customize what data about product is required on booking threre is the ability to configure the list of fields, and whether they are mandatory or optional.

To configure the list of fields,

1.  On the general settings menu, click **Product booking fields settings**:

![image-20201029-092324.png](/assets/image-20201029-092324.png)

2.  On the window appear select the product you would like to configure the list of fields and click **Edit:**

![image-20201029-092348.png](/assets/image-20201029-092348.png)

3.  Depend on your needs, select Mandatory, Optional or Disabled option.
4.  Click **Save**.

*Note! External suppliers have their own rules, on which details are required for booking. Supplier settings override the default ones and can be combinable with the settings of Tour Operator.*
