# Venues

Venues - are places, where events can take place.

*E.g. Royal Albert Hall - the concert hall in London or New York Stadium - the football stadium in UK.*

## Manage Venues

To create a new Venue,

1.  navigate to **General Settings** menu → **Venues.**Venues list is displayed:

![2024-11-27_10-35-58.jpg](/assets/2024-11-27_10-35-58.jpg)

![2024-11-27_10-38-50.jpg](/assets/2024-11-27_10-38-50.jpg)

1.  Click **Create**, *Information* pop-up for adding a new venue appears:

![2024-11-27_10-41-15.png](/assets/2024-11-27_10-41-15.png)

1.  Fill in the form with the following data: 1. **Name**: enter venue's name (a mandatory field); 2. **City**: start typing a city, then select the needed option from the available ones from database (a mandatory field); 3. **Address, Postal Code**: enter address of the venue (an optional field; once user types the address - the system should automatically add map to the screen to show location of the venue); 4. **Latitude** & **Longitude**: enter Longitude/Latitude values. If indicated, the location is shown on the map based on these values; 5. **Available for**: check additional checkboxes for what types of events this venue is available for: concert, sport, other.

To edit an existing venue, click on its name link:

![2024-11-27_10-56-36.jpg](/assets/2024-11-27_10-56-36.jpg)

To inactivate a venue, open its Information pop-up and switch **Active** toggle off, click **Save**. To activate the venue again, switch **Inactive** toggle on, click **Save**. To view inactive venues, on the list page switch **Active** toggle off:

![2024-11-27_10-57-40.jpg](/assets/2024-11-27_10-57-40.jpg)

## Link Venues to Events

It is possible to select Venues for certain event types.

For an event indicate its type and choose a venue from those which are available for this type (ex. sport / concert):

![2024-11-27_11-24-34.jpg](/assets/2024-11-27_11-24-34.jpg)

## View Venues during Search&Book and in Reservation

If there is a Venue linked to a certain Event, it is shown in the product summary and on map in the following format:

1.  location icon
2.  venue name
3.  venue address (in grey)
4.  link "show on map"
