# Ability to confirm via e-mail

If a selfoperated hotel room with availability status 'On request' was booked, hotel can confirm or reject this reservation, clicking on corresponding links immediately in e-mail notification (without necessity to sign it to Extranet).

![2024-12-26_15-32-39.jpg](/assets/2024-12-26_15-32-39.jpg)

## **Configuring notifications for your company**

**This functionality is currently available via administration panel.**

If you want the notifications to be forwarded to the general corporate mailbox, perform the following operations:

1.  On the Company profile menu, click Settings:
2.  Go to the Company notifications\*\* \*\*tab.
3.  Click Edit and select all the changes in the system you would like to be notified about.

![2024-12-26_15-32-50.jpg](/assets/2024-12-26_15-32-50.jpg)

![image-20200921-203959.png](/assets/image-20200921-203959.png)

4.  Click Save. Now all notifications are sent to the e-mail that you specify in your company details (*Company Profile -\> Information*):

![image-20200921-204710.jpg](/assets/image-20200921-204710.jpg)

## **Configuring notifications for users**

**This functionality is currently available via administration panel.**

You can configure the notification settings individually for every company user.

1.  On the Company profile menu, click Users.
2.  Select a user to include in the mailing list.
3.  Specify the e-mail of the user to which the messages should be sent.

![image-20200921-204752.jpg](/assets/image-20200921-204752.jpg)

4.  Click Save and go to the Notifications settings tab.
5.  On the Notification settings tab, select the events that you want this user to be notified about (*see Configuring notifications for your company / step 3).*
6.  Click Save.

## **Configuring notifications for partners**

**This functionality is currently available via administration panel.**

You can configure notification settings for your partners.

For that,

1.  On the Clients menu, click the required type of client.
2.  In the list of clients, click the client to include into the mailing list.
3.  In the client profile, go to the Settings tab, and then go to the Notification Settings section.
4.  On the Notification settings tab, select the events that you want this user to be notified about (*see Configuring notifications for your company / step 3).*
5.  Click Save.

Note: please remember to specify the e-mail of the partner company to which the notifications should be sent. For that, in the client profile, go to the Information tab and enter client e-mail in the respective box.

## **Configuring notifications for tourists**

**This functionality is currently available via administration panel.**

You can automatically send notifications of ticket booking to passengers' e- mails. A PDF e-ticket is attached to the notifications.

For that,

1.  On the Company profile menu, click Settings and go to the Tourists notifications tab.
2.  On the Tourists notifications tab, click Edit.
3.  Select notifications to be sent to users.
4.  Click Save.
