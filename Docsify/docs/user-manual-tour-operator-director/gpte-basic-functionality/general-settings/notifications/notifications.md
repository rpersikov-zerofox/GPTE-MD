# Notifications

You can use notifications to track all changes made to the reservations in the system and to send respective messages to all the interested parties via e-mail (managers in charge of the reservations, agents of the partner companies, etc.). To use this service you should specify the events that initiate generation of the notifications and determine the target audience that receive these notifications.

The notification settings consists of the following steps:

- [Setting supplier notifications](/wiki/spaces/GPTEUG/pages/941883743)
- [Ability to confirm via e-mail](/wiki/spaces/GPTEUG/pages/942932119)
- [Getting notifications](/wiki/spaces/GPTEUG/pages/942440719)
- [Searching for Notifications](/wiki/spaces/GPTEUG/pages/941916470)
