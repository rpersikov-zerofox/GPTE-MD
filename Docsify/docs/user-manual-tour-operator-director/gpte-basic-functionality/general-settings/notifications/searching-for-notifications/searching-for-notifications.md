# Searching for Notifications

**This functionality is currently available via administration panel.**

If the number of received notifications is sufficient and you need to search for a particular notification, you can use the search form.

**To search for a particular notification**,

1.  Click Notifications menu, use the search form on the Notifications page:

![image-20200923-172426.png](/assets/image-20200923-172426.png)

2.  Fill in the following search options: 1. **Receipt date**: specify the range of dates during which the notification was sent. 2. **Reservation number**: specify the reservation number to which the notification is bound. 3. **Notification type**: specify the action about which the notification is sent.
3.  Click Search to initiate search process. The list of notifications is limited to those fitting your search criteria.
