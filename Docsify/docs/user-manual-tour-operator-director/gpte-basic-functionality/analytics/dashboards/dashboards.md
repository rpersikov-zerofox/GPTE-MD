# Dashboards

Visual analytics dashboards provide at-a-glance views of sales performance, booking trends, and key business metrics. Different dashboard widgets appear based on your company type and user role.

## Overview

Dashboards display real-time business intelligence through interactive widgets showing:

- Sales summaries and revenue
- Booking trends over time
- Top performing destinations and products
- Agent and client performance
- Trip calendars (for corporate clients)

**Note:** Basic dashboard widgets are included with the platform. Extended analytics features are available through the Business Intelligence module. Contact your account manager for advanced reporting capabilities.

## Access Dashboards

Navigate to **My Company** > **Dashboards**

Access requires Supervisor or Director role permissions.

## Dashboard Types

### Tour Operator Dashboards

First-level tour operators (TO1) see comprehensive sales analytics:

![Tour operator dashboard](/assets/2024-12-27_12-55-57.jpg)

**Available Widgets:**

1. **Summary** - Overview metrics
   - Total profit
   - Number of reservations
   - Total turnover

2. **Reservations by Month** - Booking volume trends over time

3. **Top Clients/Distributors** - Highest revenue-generating agencies and direct clients

4. **Top Agents** - Best-performing sales staff by bookings or revenue

5. **Top Destinations** - Most popular travel locations

6. **Top Products** - Best-selling services (hotels, flights, tours, etc.)

**Currency:** All reports display in your system currency.

![Tour operator dashboard details](/assets/2024-12-27_12-56-24.jpg)

### Travel Agency Dashboards

Travel agency (TA) users see similar metrics with agency-specific modifications:

![Travel agency dashboard](/assets/2024-12-27_13-05-10.jpg)

**Widget Differences:**

1. **Summary** - Shows commission instead of profit
   - Total commission earned
   - Number of reservations
   - Total turnover
   - **Note:** If no commissions configured, only reservations and turnover display

2. **Reservations by Month** - Same as tour operator view

3. **Top Clients** - Renamed from "Top Clients/Distributors" to simply "Top Clients"

4. **Top Agents** - Agency staff members with most bookings

5. **Top Destinations** - Same as tour operator view

6. **Top Products** - Same as tour operator view

**Currency:** Reports display in both:
- System currency
- Agency currency (as specified in contract settings)

### Corporate Client Dashboards

Corporate clients (CC) see travel-focused metrics for business trip management:

![Corporate client dashboard](/assets/2024-12-27_13-16-34.jpg)

**Available Widgets:**

1. **Summary** - Business travel metrics
   - Total trips (not "reservations")
   - Total travel expenses

2. **Trips by Month** - Business trip volume trends

3. **Top Destinations** - Most frequently traveled locations

4. **Trip Calendar** - Unique to corporate clients
   - Shows all scheduled trips on calendar
   - Displays trip number and duration
   - Shows lead traveler name for each trip

![Corporate trip calendar](/assets/2024-12-27_13-16-44.jpg)

**Widgets Not Displayed:**
- Top Agents
- Top Products
- Top Clients

## Widget Functionality

### Interactive Features

Most dashboard widgets support:

- **Date Range Selection** - Filter data by time period
- **Drill-Down** - Click widgets for detailed views
- **Export** - Download data for external analysis
- **Refresh** - Update data to current values

### Data Refresh

Dashboard data updates:

- Automatically at regular intervals
- Manually by refreshing the page
- In real-time for some widgets

**Note:** Some data may have a slight delay depending on system load and data volume.

## Using Dashboards Effectively

### For Tour Operators

- Monitor profit trends to adjust pricing strategies
- Track top destinations to focus marketing efforts
- Review agent performance for training and incentives
- Identify best-selling products for inventory management

### For Travel Agencies

- Track commission earnings across suppliers
- Monitor agent productivity
- Identify high-value client relationships
- Analyze booking patterns for resource allocation

### For Corporate Clients

- Monitor travel expenses against budgets
- Review trip patterns for policy compliance
- Plan ahead using trip calendar
- Identify cost-saving opportunities in frequently traveled routes

## Troubleshooting

**Dashboard Not Loading:**
- Check your role permissions (requires Supervisor or Director)
- Verify you're accessing the correct dashboard for your company type
- Refresh your browser

**No Data Displaying:**
- Confirm reservations exist in the selected date range
- Check filter settings
- Verify data synchronization is complete

**Wrong Currency Showing:**
- Review contract settings for currency configuration
- Check system currency settings in Company Profile
