# Trip Variants

For trip quotations, it often happens that agent may plan few alternatives for the trip - e.g. arriving with this or that flight or staying in one of the alternative hotels.

Within reservations it is possible to mark some services with tags - to which variant they relate:

![2024-12-26_14-16-10.jpg](/assets/2024-12-26_14-16-10.jpg)

When clicking on Add variants, enter needed tag text:

- any free text can be used
- multiple tags can be specified as well. e.g. "Variant1", "Variant2".

![2024-12-26_14-28-29.png](/assets/2024-12-26_14-28-29.png)

## Filter by variant

Within reservations it is possible to view only services related to certain variant of the trip.

![2024-12-26_14-28-49.png](/assets/2024-12-26_14-28-49.png)

1.  The *Show trip variant* drop down contains all variants that were created, sorted in alphabetical order.
2.  By default it is empty, that means that all services are to be shown.
3.  When user selects any variant in the drop-down, services are shown: 1. marked with this variant 2. do not marked at all (it's assumed that they relate to all variants)

![2024-12-26_14-38-50.jpg](/assets/2024-12-26_14-38-50.jpg)

When a Trip variant is selected:

- the total amount of a reservation is calculated based on variant (in summary section on the right)
- services for the selected trip variant are shown on itinerary and table display views (total amounts for the table display view are calculated under the table based on the variant)
- services on the documentation are shown based on the variant (as service row, total amount and breakdown section on payments)
