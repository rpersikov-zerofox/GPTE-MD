# Editing reservations

There are the following possibilities for editing the reservation:

- To add a remark to the reservation number, click the symbol opposite the reservation number. Enter the remark and click **Save**. (See group 1 in the figure below.)
- In case you want to ascribe the reservation to another manager, click the symbol opposite the manager name. Select manager window appears. Select the required person from the drop-down and click **Save**. (See group 2 in the figure below.)
- In case there is a need to change the reservation status, for example if the supplier demands the revision of the reservation, you can change the reservation status. For that, click the symbol opposite the reservation status, select the required status from the drop-down (e.g. in progress, done), and click **Save**. (See group 3 in the figure below.)
- If you want to view a history of modifications made to the reservation, click **History**. (See group 4 in the figure.) The history log appears, where you can see all the modifications, the time they were made and the user by whom they were made.
- If you need to ask for or share certain information on the reservation, you can use a built-in chat. Click **Chat**. (See group 5 in the figure below.)The Chat pop-up appears.
- For the simplifying of work with reservations after booking there is a possibility to add and edit comments for services and internal notes for reservations.

## Adding Destinations

One of the most important Reservations enhancements is Destinations functionality. It's useful for planning long trips (e.g. 20 days and more).

It's possible to add multiple destinations in reservation. All cities and geographical areas are displayed separately and all the services relate to the corresponding destinations now.

Note: This functionality is available as a part of "Itinerary builder" module

![2024-12-26_12-14-27.jpg](/assets/2024-12-26_12-14-27.jpg)

When user clicks "Add Destination" - system opens a pop up window where user can select target destination and dates:

![2024-12-26_12-17-16.png](/assets/2024-12-26_12-17-16.png)

After destination is added - it's shown in the trip - on tabs "List of Services" and "Itinerary" with:

- Icons "edit" and "delete"
- Links "Add service" and "Add offline service"

![2024-12-26_12-19-11.png](/assets/2024-12-26_12-19-11.png)

When user clicks "Add service" from here - the default destination and dates in search form for all products should be set to what is chosen:

![2024-12-26_12-21-26.jpg](/assets/2024-12-26_12-21-26.jpg)

After adding service - it is shown within this destination.

## Hidden services

A new logic of hidden services for the documentation was also implemented on the reservation to be able to include some component into total price of package, but not show it for client (like "handling fee", additional surcharges, etc.).

## Short and full description

To be able to view the full description of Products in a reservation the functionality of 'Information' icon was extended.
