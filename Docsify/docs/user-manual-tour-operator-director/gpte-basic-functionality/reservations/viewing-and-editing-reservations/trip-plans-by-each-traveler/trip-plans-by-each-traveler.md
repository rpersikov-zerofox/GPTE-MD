# Trip Plans by Each Traveler

For complex business trips it might happen that there are 5-10 travelers for one trip who arrive on different dates with different flights, require different transfers and have hotel reservations with overlapping dates.

Still it can be the same trip e.g. for some event.

In order to double check that nothing is missed for all participants and be able to print for every person individual itinerary - filtering services by traveler within reservations are implemented.

![2024-12-27_13-44-38.jpg](/assets/2024-12-27_13-44-38.jpg)

By default services for all travelers are shown (*Show trip plans for* drop-down is empty).

Within drop-down "Show trip plans for" user can select any of travelers participating in trip - and in this case only services related to this person are kept.
