# Assigning Reservation Managers

To assign or re-assign a reservation manager,

1.  On the Reservations menu - Reservations page, select the required reservations:

![2024-11-01_12-28-47.jpg](/assets/2024-11-01_12-28-47.jpg)

2.  Click **Edit reservations**. **Change selected request** window appears:

![2024-11-01_12-30-53.jpg](/assets/2024-11-01_12-30-53.jpg)

3.  From the drop-downs, select the reservation manager and/or the service manager.
4.  Click **Save**.
