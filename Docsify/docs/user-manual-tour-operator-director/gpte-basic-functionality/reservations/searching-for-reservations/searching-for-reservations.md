# Searching for Reservations

To search for particular reservations, use the search form at the top of the page:

![2024-10-29_23-17-42.jpg](/assets/2024-10-29_23-17-42.jpg)

The search form contains basic and additional search options.

**Basic search options:**

- **Reservation number**: enter reservation number by which you would like to search.
- **Traveler name or surname**: enter the name or surname of the traveler for whom the reservation was made. In case there are several travelers in the reservation, enter the name of a tour lead.
- **Service status**: select needed service status value from the dropdown. More than 1 value can be selected.
- **Reservation status**: select needed reservation status value from the dropdown. More than 1 value can be selected
- **Apply filter to services** toggle can be activated if needed.
- One of **All reservations, Future trips, Past trips and Cancelled trips** options can be specified to narrow the selection.

To expand the **additional** search options, click **Additional parameters**. The search form expands:

![2024-10-29_23-25-19.jpg](/assets/2024-10-29_23-25-19.jpg)

The additional search parameters include the following groups:

  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Trip details**      In the Trip details group, specify the following criteria: \* **Create date from/to**: specify the dates of reservation creation. \* **Modified date from/to**: specify the dates of reservation modification. \* **Start date from/to**: specify the dates of reservation trip start. \* **End date from/to**: specify the dates of reservation trip end. \* **Last ticketing/due to confirm from/to**: specify the last ticketing dates. \* **Service type**: select the service render in the reservation (transfer, accommodation etc.). \* **Ticket number**: specify the number of associated ticket. \* **Service name**: in case you look for a particular service, enter its name (e.g. the name of the excursion --London Bridges). \* **Destination**: specify the destination location of the reservation. \* **Promo code**: specify the promo code associated with the reservation. \* **Campaigns**: select a campaign value from the dropdown. \* **Reservations manager**: enter the name of a company employee who supervises the reservation you search for. \* **Booked from**: specify the value from dropdown by means of which the reservation was booked.
  --------------------- -----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  **Supplier**          In the Supplier group, specify the following options: \* **Supplier name**: specify the required supplier's name. \* **Supplier ref**: specify the required supplier's reference number. \* **Supplier invoice status**: select the status of the supplier invoice from dropdown. \* **Supplier payment status**: select the status of the supplier payment. \* **Supplier penalty**: select the status of the supplier penalty. \* **Supplier payment due date from/to**: specify the dates range of supplier payment.

  **Client**            In the Client group, specify the following criteria: \* **Client name**: enter the client name. \* **Customer company**: enter the name of the company. \* **Agent name**: enter the name of the agent who is responsible for the reservation. \* **Client invoice status:**select the status of the invoice. \* **Client payment status:**select the status of the payment. \* **Client penalty**: select the status of the customer penalty. \* **Payment method**: select payment method value. \* **Client payment due date from/to**: specify the dates range of client payment.

  **Booking details**   In the Booking details group, specify the following options: \* **Booking date from/to**: specify the dates of reservation booking.
  ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Please mind the distinction between reservations and services. One reservation may contain several services. That is why it is important to define whether you apply filters to reservation or to service. Otherwise, you can receive no search results.

As soon as all the necessary search criteria are filled in, click **Filter** to initiate search process.

Entered search criteria can be saved clicking "Save this filter" icon:
