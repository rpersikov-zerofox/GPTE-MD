# Adding Documents to a Reservation

If needed, you can attach different documents to the reservation, e.g. hotel invitations, traveler's passports and so on. For that,

1.  Go to the **Attachments** tab of the reservation and click **Add**.

![2024-11-18_22-48-48.jpg](/assets/2024-11-18_22-48-48.jpg)

2.  In the **Attachments** pop-up:

- upload a file from your local folder,
- specify the service which the file relates to,
- select *Hide cancelled services* option if needed,
- set the file visibility,
- click **Upload**.
