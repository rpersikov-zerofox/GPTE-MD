# Mass Receiving or Issuing Invoices for Reservations

**This functionality is currently available via administration panel.**

To receive or issue invoices for the number of reservations at a time:

1.  On the Reservations menu, click **View reservations**.

![image-20201012-084604.jpg](/assets/image-20201012-084604.jpg)

2.  Select the reservations for which you want to receive/issue invoice.

![image-20201012-084648.jpg](/assets/image-20201012-084648.jpg)

3.  Click **Receive / Issue invoice**. Invoicing window appears:

![image-20201012-084734.jpg](/assets/image-20201012-084734.jpg)

4.  In the\*\* Invoicing\*\* window, click the button of your choice -- either get or issue an invoice.
5.  Click **Continue**, and then choose whether to save the invoice to PDF or to Excel. Click the respective button.
