# Commission setting

To set up commission plan,

1.  On the Prices tab → Commission sub-tab, click **Create**:

![2024-11-11_15-41-58.jpg](/assets/2024-11-11_15-41-58.jpg)

2.  On the Commission creating page, specify *the commission name*, the tariff, *the period* when it is active and *the description*. Select the currency in which the commission is set.
3.  Specify *Commission per tourist* and *Commission for extra services.*
4.  Choose the transfer type radio-button from the *Commission applied for the following transfer types*\*\* \*\*section
5.  Click **Save**.
