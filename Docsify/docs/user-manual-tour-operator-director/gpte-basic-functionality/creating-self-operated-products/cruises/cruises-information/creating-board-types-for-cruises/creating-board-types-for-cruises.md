# Creating Board Types for Cruises

To add a new board type for cruises,

1.  Open the product.
2.  On the Information tab, Board type sub-tab, click **Create**. *Create board type* window appears:

![2024-11-14_14-27-39.jpg](/assets/2024-11-14_14-27-39.jpg)

1.  In the window, fill in the required information: \* **Name**: enter the name of the meal type as it is specified by hotel (e.g. "Full Board"). \* **Type**: select the meal type from the drop-down (e.g. All Inclusive). \* **Default**: select the default check box to apply the meal type under configuration as default. \* **Description**: locate mouse pointer into the *Short description* and *Description* boxes and enter the meal type description. \* **Use for the following tariffs**: specify the conditions of the board type application: \* **Offer on Search results**: the board type is displayed as a main option on search the search results page. \* **Offer as alternative**: the board type is displayed when clicking Show all offers and can be selected instead of the main option. \* **Not available**: the board type is not available within the borders of the selected tariff.
2.  Click **Save**.
