# Creating Accommodation Types for Cruises

For self-operated cruises you should specify all options of accommodation available for tourists.

To add a new **accommodation type**,

1.  Open the required Cruise.
2.  On the Information tab, Accommodation sub-tab, click **Create**. *Create accommodation* window appears:

![2024-11-14_14-13-54.jpg](/assets/2024-11-14_14-13-54.jpg)

4.  In the Accommodation window, specify the following information:

- **Name**: locate mouse pointer into the box and type the name of the accommodation option.
- **Type**: from the drop-down, select the accommodation type in regard to its capacity, e.g. *a single, double, family room, etc.*
- **Category**: from the drop-down, select the accommodation option category. The category list displays only the entries that your create in the cruise directory.
- **Description**: locate mouse pointer into the text field and type the cruise description to display on the search results.
- **Capacity, Extra bed, Sharing place**: specify the room capacity, number of extra beds and sharing places for the accommodation type.

5.  Click **Save**.
