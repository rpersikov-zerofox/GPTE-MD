# Setting Info for Cruises

To create a new cruise,

1.  On the **Products** menu click **Cruises**.
2.  On the Cruises page, click **Create**. *Create new cruise* page appears:
3.  On the *Create new cruise* page, specify the following information:

![2024-11-14_13-56-33.jpg](/assets/2024-11-14_13-56-33.jpg)

- **Name**: type the name of a cruise.
- **Product name for Supplier**: add a cruise name as a supplier calls it.\*\* \*\*The product name for the supplier is used in notifications to the supplier.
- **Supplier**: select the service supplier. Here you can choose either your own company (if you organize the cruise by yourself) or the supplier, from whom you get this cruise product.
- **Default currency:** select the currency to use for settlements with supplier. The selected currency will also be used for configuring tariffs, price-lists, etc.
- **Starting location:**select from the list Country and City, from where cruise will departure.
- **Ending location:**select from the list of cities the destination Location of the Cruise clicking **Add** button:

![2024-11-14_13-58-35.jpg](/assets/2024-11-14_13-58-35.jpg)

- **Duration (days)**: type the numbers days which the cruise includes.
- **Internal notes**: additional notes about the cruise product.

1.  Click **Save**.

To add descriptions for the created cruise, navigate to **Description** tab and specify the following information:

- **Short description:**enter a brief cruise description. The description will be displayed on the Search results page.
- **Full description:**enter a cruise description. This description will be displayed in the window with the detailed description of the cruise.
- **Important information**: enter other important details.

Save the changes.

To upload cruise picture(s) - to configure how it should appear on search results and within the reservation details, navigate to **Photo** tab:

- To upload a picture from your PC, click at the *Select photos* field, browse to the picture you want to upload, click **Open**.
- Click **Save**.
