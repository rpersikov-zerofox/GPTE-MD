# Creating Catalogue for Cruises

## Creating Catalogue

You can organize categories of self-operated cruises as directories and avoid creating them for every cruise. The directory contains the list of categories.

To create cruise catalogue items, navigate to **Information** tab → **Catalogue** sub-tab and click **Create.**Specify the name and click **Save** in the *Create category*window. The created category is displayed in the Catalogue list:
