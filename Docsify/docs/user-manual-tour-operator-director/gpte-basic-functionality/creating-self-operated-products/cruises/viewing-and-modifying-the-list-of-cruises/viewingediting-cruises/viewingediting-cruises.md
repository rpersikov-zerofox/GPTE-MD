# Viewing/Editing Cruises

To view or edit a tour,

1.  On the **Products**menu click **Cruises**.
2.  In the table of cruises click the required one.

![2024-11-14_16-01-36.jpg](/assets/2024-11-14_16-01-36.jpg)

3.  The Cruise page appears:

![2024-11-14_16-02-27.jpg](/assets/2024-11-14_16-02-27.jpg)

4.  Go to the required tab and make necessary corrections.
5.  Click **Save**.
