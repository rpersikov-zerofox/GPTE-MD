# Commission setting for Excursions

To set up commission plan,

1.  On **Products** → Excursion **Prices** tab → **Commission** sub-tab click **Create**, *Commission creating* page appears:

![2024-11-12_11-09-26.jpg](/assets/2024-11-12_11-09-26.jpg)

![2024-11-12_11-09-35.jpg](/assets/2024-11-12_11-09-35.jpg)

2.  Specify *the commission name*, as well as the *tariff*, *the period* when it is active, *the description and the currency for commission calculation (b*y default the base currency of the hotel is used. But you can change it to any other value).
3.  Specify:

- **Commission per tourist:** specify single commission for the tourist.
- Choose the needed option(s) from the **Commission applied for the following excursion types**section.
- **Commission for extra services.**

4.  Click **Save**.
