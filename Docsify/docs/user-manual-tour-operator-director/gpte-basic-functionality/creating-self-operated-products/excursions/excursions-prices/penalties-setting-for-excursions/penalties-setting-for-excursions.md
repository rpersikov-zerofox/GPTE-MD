# Penalties setting for excursions

To set up a penalty for excursion,

On **Products** → Excursion **Prices** tab → **Penalties** sub-tab click **Create**, *Penalties creating* page appears:

![2024-11-12_11-25-08.jpg](/assets/2024-11-12_11-25-08.jpg)

1.  Specify the following information:

- **Name**: type the name of the penalty plan.
- **Description (for internal use and for tourists)**: in the text field describe the penalty plan.
- **Penalty conditions**: in the group specify the conditions for penalties application and the cancellation charges: \* from the drop-down select the number of days before the check-in date when the penalties are applied. \* select whether to calculate penalties in currency units or in per cent from a certain sum. \* in case the penalties are calculated in per cents, specify the price from which they are calculated: total price or a price for a particular number of nights/days.

To add another penalty rule, click **Add** button.

- **Penalties are active during**: in the group, specify the tariff for which the penalty plan will be applied and the terms of its application.

2.  Click **Save**.
