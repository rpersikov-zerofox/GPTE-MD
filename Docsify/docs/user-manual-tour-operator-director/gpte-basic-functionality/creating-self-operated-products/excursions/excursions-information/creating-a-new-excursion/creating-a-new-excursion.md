# Creating a new excursion

To add information about a new activity,

1.  On the **Products** menu, click **Activities**.
2.  On the Activities page, click **Create**→\*\* **choose** Excursion \*\*category. *Create new activity* window appears:

![2024-11-12_09-58-22.jpg](/assets/2024-11-12_09-58-22.jpg)

![2024-11-12_10-00-13.png](/assets/2024-11-12_10-00-13.png)

3.  On the *Create new activity* page, specify the following information:

- **Recommended**- is implemented for own excursions. If to switch on this option, you can sort products by option "Recommended" on the results search page on the Website
- **Product variant:**select the product type City Tour or Extreme tour.
- **Name**: enter the name of the excursion.
- **Product name for Supplier**: add a product name as a supplier calls it.\*\* \*\*The product name for the supplier is used in notifications to the supplier.
- **Supplier**: select the excursion service supplier.
- **Excursion type**: select if the excursion is shared or private, walking or off site.
- **Default currency**: select the currency to use for settlements with the service supplier. The selected currency will also be used for configuring tariffs, price-lists, etc.
- **Duration**: specify the excursion duration - approximate time the excursion will take.

We improved option "Duration" for own excursions. Now it is possible to specify the duration not only for single day excursion. If it's needed you can choose multi-day tour and specify the duration in days. This information is displayed on the search results page and reservation details page on the back office and Website.

- **Starting and ending location**: \* Click **Add** to specify the departure and destination points for an excursion. Within the pop-up window either type or select from the list the required city name and then the location - a hotel or a place in the city. Note that both starting and ending points are mandatory:

![2024-11-12_10-00-48.jpg](/assets/2024-11-12_10-00-48.jpg)

Added some **changes to Departure/Destination points settings**for Excursions:

- Took into account popularity of cities for corresponding drop down
- Added ability to define Excursion Departure/Destination points as "Hotel/Address"  (previously it was only hotel)
- To add another starting location, in the Starting location form, click **Add**. The Starting location window appears. However it contains minor changes: Fill in the required boxes the way it is described above. Locate mouse pointer into the **Shift in time** box and specify the time shift of the departure as compared to the departure time from the previous location. *Assume you plan to get tourists at several locations. When you create an excursion the time shift for the first location is set to 0 by default, while the time shift for the second one should be specified. E.g. distance between the first and the second location is 10km and it takes 15 minutes to get to the second point. In case it should be set to +00:15 as shown in the figure above, that means that the coach brings tourists to the second location in 15 minutes after the first one. And after collecting tourists from both locations the coach will continue it's route.*

After you have finished to fill in all the details click **Save**. Your excursion will be saved into the system. Open the created excursion product and navigate to **Description** tab and enter corresponding information:

- **Short description**: briefly describe the excursion service. The entered description will be displayed on Search Results page.
- **Description**: enter the excursion description. The information entered in the field will be displayed for tourists in the Detailed information on the excursion window. Here we recommend to specify the details of meeting point, whether the additional services are available, etc.
- **Important information**: enter additional important details.

4.  Click **Save**.
