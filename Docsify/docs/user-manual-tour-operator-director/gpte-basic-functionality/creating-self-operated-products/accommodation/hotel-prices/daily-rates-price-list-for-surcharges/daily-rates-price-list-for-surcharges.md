# Daily rates / Price-list for surcharges

**This functionality is currently available via administration panel.**

In order to specify the daily rates for accommodation,

1.  Go to the required tariff and indicate **Use daily rates** in Price-lists section. Save the changes.
2.  On the Prices tab, click **Daily rates**, and then carry out the mass edit:

![image-20200929-093031.jpg](/assets/image-20200929-093031.jpg)

3.  There are 4 options to edit the daily rates: 1. **Set rates.** The obligatory parameters for setting rates are period, room type, tariff and price. It is also possible to indicate days of the week and minimum and maximum nights of stay to advance the offer\'s exclusiveness

![image-20200929-093115.png](/assets/image-20200929-093115.png)

![image-20200929-093201.png](/assets/image-20200929-093201.png)

![image-20200929-093257.png](/assets/image-20200929-093257.png)

![image-20200929-093548.png](/assets/image-20200929-093548.png)

Since the daily rates are usually set up per room for default quantity of guests, some additional surcharges can be set to base prices on extra beds / sharing places or meal types for self-operated hotels. Once a price-list for surcharges is created and added to an active tariff, surcharges will be included in client's price. As of now, surcharges are compatible only with daily rates.

**Max number of days for daily rates** is changed up to 730. It is possible to add price for period of 2 years (up to 730 days) for daily rates of own hotels.

![image-20200929-094105.jpg](/assets/image-20200929-094105.jpg)

In order to create a price-list **for surcharges**,

**This functionality is currently available via administration panel.**

1.  Fill in the general information for such a price-list specifying its name, applicable tariff, the period and description (optionally):

![image-20200929-094307.jpg](/assets/image-20200929-094307.jpg)

2.  Configure prices for the surcharges: 1. Meal types depending on the board plans indicated in the hotel\'s contract. 2. Additional surcharge for room types. Due to the fact that setting prices for hotels can often depend on surcharges or reductions to / from the base price, for example, a surcharge for a category or discount for single occupancy, it is possible to calculate price per room based on chosen room type.

![image-20200929-094755.jpg](/assets/image-20200929-094755.jpg)

3.  Go to Daily rates and open the Room types tab. It is needed to indicate the base room type and assign it to the rooms that are meant to inherit its price:

![image-20200929-094815.jpg](/assets/image-20200929-094815.jpg)

4.  Following this step, the surcharges have to be specified in the price-list:
