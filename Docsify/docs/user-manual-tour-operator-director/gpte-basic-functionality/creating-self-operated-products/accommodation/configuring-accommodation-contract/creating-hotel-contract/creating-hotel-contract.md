# Creating hotel contract

## Entering information about a hotel

The first tab is for general contract conditions.

1.  In the **Name** box, enter the name of the hotel.

![2024-11-15_11-01-16.jpg](/assets/2024-11-15_11-01-16.jpg)

2.  Fill in\*\* Product name for supplier\*\*: add a hotel name as a supplier calls it.\*\* \*\*The product name for the supplier is used in notifications to the supplier.
3.  From the **Supplier** drop-down select the service supplier. Note that in the list only direct contracted suppliers and your company are available. *It is very important to fill this field correctly. If you choose your own company as a supplier the system will consider that your company itself is a hotel owner. This means that the system will not be able to send any data to hotels and calculate settlements with them. That is why you need first to create a hotel supplier (from which you buy this hotel) and then select this supplier in hotel contract settings.*
4.  From the **Default currency** drop-down, select the currency to use for payment with the supplier.
5.  Select the **Same board type for all guests**check box in case you do not allow differing meal types for the tourists in the same room. Or keep this option unchecked if you allow to book different meals for different tourists within the same booking.
6.  Select Allow booking for children without adults option if needed for the configuration.

## **Creating extra services for self-operated products**

For self-operated products you can specify the list of extra services available for tourists.

To add an extra service to a contract of a self-operated hotel,

1.  Open the profile of a required self-operated hotel.
2.  On the **Information** tab → **Extra services** sub-tab click **Create**. *Extra Service* page appears:

![2024-11-15_11-01-30.jpg](/assets/2024-11-15_11-01-30.jpg)

![2024-11-15_11-24-02.jpg](/assets/2024-11-15_11-24-02.jpg)

3.  On the *Extra service* page, specify the following information: 1. **Name:** locate mouse pointer into the box and type the name of the additional service. 2. **Service category:** from the drop-down, select the category of the additional service (transfer, SPA, early check-in, etc.). In case there is no item that suites you, select **Other**. 3. **Price per:** In the group specify the method of price calculation: either per service, guest or bedroom. 1. In case you select per **service**, while creating price-lists for additional services, you will be asked to specify the price for the service itself. For example, in case you offer a transfer to an airport, you set a fixed price of \$40 for the transfer irrespective of the number of tourists. 2. In case you select per **guest**, the total price for the additional service --- is the sum of the prices payed by the tourists who buy the service. Pay attention that, in case the price is calculated per tourist, you should specify the tourist type: via *Guests categories* options below. 3. in case you select per **bedroom**, the total price for the additional service --- is the sum of the prices payed per bedrooms associated with the service. 4. **Calculation type:** In the group determine the method the price of additional service is calculated --- on a single occasion by service or depending on the number of days or nights. Click the button of your choice. 5. **Guests categories**: select the category type - whether it refers to adults or children. 6. **Offer this extra service:** In the group, specify the conditions of the additional service availability in relation to room types, meal types and membership level. In case you want the service to be available for all types of the certain section, click **All**. 7. **The service is provided by:** select the service provider, either a hotel or a tour operator. 8. **Description:** locate mouse pointer into the text field and describe the service
4.  Click **Save**. The additional service is added to the list of available additional services and displayed on the Extra services page.

## **Creating guest categories for self-operated products**

You may differentiate prices for self-operated products depending on the category of tourists who buy them. For instance, adjust the allocation price rate depending on the age of a tourist. For example the number of hotels and airlines provides discounts for children. The Adult guest category is created in the system by default.

**To create a new guest category,**

1.  Open the profile of the required self-operated product.
2.  On the **Information** tab → **Guests categories** sub-tab, click **Create**. *Tourist* page appears:

![2025-01-10_10-45-41.jpg](/assets/2025-01-10_10-45-41.jpg)

3.  On the *Tourist* page, specify the following information: \* **Name**: type the name of the category. \* **Category**: select the category type - whether it refers to adults or children. \* **Default**: generally the Adult tourist category is created automatically and set as default. However you can change the default category selecting the **Default** check box. \* **Age**: specify the age range acceptable for the category. *Please pay attention that in case you create several tourist categories (e.g. infant, child), the age ranges should not overlap. Thus, in case age range for Infant is***\*0**\*\* to \*\*\*\*2\*\*\*\*, the age range for Child should start with \*\*\*\*3\*\*\*\* years old.\* \* **Description**: describe the guest category.
4.  Click **Save**. The new guest category is added to the list of available categories.
