# Creating Board Types

To add a new board type,

1.  Open the product.
2.  On the Information tab, **Meal types** sub-tab, click **Create**. *Create meal type* page appears:

![2024-11-15_10-23-26.jpg](/assets/2024-11-15_10-23-26.jpg)

3.  On the *Create meal type* page, fill in the required information: \* **Name**: enter the name of the meal type as it is specified by hotel (e.g. "Vegetarian Breakfast") \* **Type**: select the meal type from the drop-down \* **Meal code**: enter the code of the meal type \* **Default**: select the default check box to apply the meal type under configuration as default. \* **Description**: locate mouse pointer into the *Short description* and *Description* boxes and enter the meal type description.
4.  Click **Save**.
