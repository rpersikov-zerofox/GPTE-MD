# Viewing/Editing Accommodations

To view or edit accommodation,

1.  Go to **Products** and click **Hotels**.
2.  In the table of results, in the name column, click the required accommodation. The accommodation information tab appears:

![2024-11-11_18-40-31.jpg](/assets/2024-11-11_18-40-31.jpg)

3.  In order to edit accommodation contract, 1. Go the required tab and make necessary corrections. 2. Click **Save**.
4.  In order to edit accommodation description, 1. click **Description**tab. 2. The accommodation description page appears:

![2024-11-11_18-43-26.jpg](/assets/2024-11-11_18-43-26.jpg)

Please pay attention that in case accommodating description was imported from external suppliers no corrections can be applied.
