# Adding Driver Categories

By default the system creates Driver 18+ category. You can create other categories, if you plan to set separate prices for different driver types. To create a new driver category,

1.  On the **Products** menu, click **Cars Hire**.
2.  Click the required car hire product.
3.  On the **Information** tab, **Drivers sub-tab**, click **Create**. The New driver window appears:

![2024-11-11_22-30-30.jpg](/assets/2024-11-11_22-30-30.jpg)

4.  In the New driver window, specify the following information: 1. **Name**: type the category name. 2. **Default**: select the check box to appoint the category you create as default. 3. **Age**: specify the age range for the category. 4. **Description**: enter the category description.
5.  Click **Save**. The new driver category is created and added to the list of driver categories.
