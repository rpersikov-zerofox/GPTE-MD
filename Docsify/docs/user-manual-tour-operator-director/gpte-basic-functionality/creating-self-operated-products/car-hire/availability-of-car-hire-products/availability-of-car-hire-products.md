# Availability of Car Hire Products

With the seat allotments you can indicate the number of seats that are currently available and specify the dates of service booking. To set car allotments,

1.  Select the necessary operation from the list. You can select the following operations (\*\* is currently available via administration panel\*\*): 1. **Set up allotment**: set up a number of allotments (guaranteed quotas) allocated to you by the supplier. 2. **Terminate allotment**: cease sales for a certain period. For instance, if the supplier recalls the allotment. 3. **Block out**: set up periods when the service is not available for booking, for instance, during fairs and exhibitions. 4. **Set release**: release is the number of days after the booking when the supplier does not guarantee the allotment and therefore confirmation of the service availability from the supplier is required. **\*Example:**\* 1. *Suppose today is January 1.* 2. *You have an allotment for 10 units (10 seats in the car).* 3. *The release lasts for 7 days according to the agreement with a supplier.* 4. *This means that you can book up to 10 services a day, starting from January 8. The bookings that are made from January 1 to January 7 are not confirmed automatically and are processed "upon request".* 5. **Set be default**: resets the number of allotments to the initial value (0, by default means, that the hotel is available upon request only).
2.  Set up operation parameters.

3.  Specify the number of allocated units in the Quantity group.

![image-20200921-085004.png](/assets/image-20200921-085004.png)

Suppose you have an agreement with the supplier on 50 cars available for rent The cars are offered upon request for the period from June 1 to June 30. To set this number of guaranteed allotments in the system:

1.  Click **Set Allotment**.
2.  Set the time span from June 1 to 30.
3.  Select the required allotment, category and vehicle type.
4.  In the Quantity group, click **Limited** and specify the number of cars that you can offer.
5.  Click **Update**.

The number of guaranteed rooms that you set appears in the table.

All conditions of the availability configured in this block are taken into account during the booking.

Once a car is booked for a certain period, the number of available rooms respectively decreases.
