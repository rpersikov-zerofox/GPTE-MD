# Commission setting for Events

To set up commission plan,

1.  On **Products** → Event **Prices** tab → **Commission** sub-tab click **Create**, *Commission creating* page appears:

![2024-11-12_15-57-39.jpg](/assets/2024-11-12_15-57-39.jpg)

![2024-11-12_15-57-50.jpg](/assets/2024-11-12_15-57-50.jpg)

1.  Specify *the commission name*, as well as the *tariff*, *the period* when it is active, *the description and the currency for commission calculation (b*y default the base currency of the hotel is used. But you can change it to any other value).
2.  Specify,

- **Commission per tourist:** specify single commission for the tourist.
- Choose the transfer type radio-button from the **Commission applied for the following event types**section.
- **Commission for extra services.**

4.  Click **Save**.
