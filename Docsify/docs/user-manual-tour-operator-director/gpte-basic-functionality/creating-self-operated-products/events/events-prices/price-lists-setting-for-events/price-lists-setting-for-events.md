# Price-lists setting for Events

To set up a price-list for event,

On **Products** → Event **Prices** tab → **Price-lists** sub-tab click **Create**, *Price-list creating* page appears:

![2024-11-12_15-38-08.jpg](/assets/2024-11-12_15-38-08.jpg)

1.  Specify the *name*of the price-list, the *tariff*, the *days of the week* on which it will be valid and the description. If needed, you can create different price-lists for week days and weekends.
2.  In the **Prices** section, select the method of price calculation (considering the service and the type) and specify the rates for all services and types:

- In case **the price is the same for all the services** is selected, one single price rate is set for the event irrespective of the services included.
- In case **the price depends on the type and the time of service** is selected, you should specify a separate price rate for the event types and services included in the event.

3.  Click **Save**.

The prices for activities sometimes depend on quantity of passengers in the group, and such logic is also supported in GP Travel Enterprise. For each product you can create as many ranges as required according to your original prices from suppliers.
