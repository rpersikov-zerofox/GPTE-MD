# Viewing/Editing Events

To view or edit an excursion,

1.  On the **Products**menu click **Activities**.
2.  In the table of activities click the required event.
3.  The Event page appears:

![2024-11-12_23-23-45.jpg](/assets/2024-11-12_23-23-45.jpg)

4.  Go to the required tab and make necessary corrections.
5.  Click **Save**.
