# Viewing the List of Events

To view the list of events, on the Products menu, click **Activities**. Click *Filter* and select **Event** in *Category* drop-down, click **Filter**:

![2024-11-12_23-20-54.jpg](/assets/2024-11-12_23-20-54.jpg)

- The entries in the table are sorted by the Name. In order to change the sorting criterion, click the corresponding column header.
- To change the order of sorting, click the column one more time. For example in case sorting by name is applied, the entries in the table are sorted from A to Z. To apply the reverse sorting order, click Name column head. The entries are now sorted from Z to A.
- In case the number of entries in the list is sufficient or if you need to find a particular event, use the search form at the top of the page:
- In the search form, fill in the boxes and click **Filter**. the list of events will be contracted to those fitting your search criteria. To clear the search form and return to the initial state, click **Reset**.
