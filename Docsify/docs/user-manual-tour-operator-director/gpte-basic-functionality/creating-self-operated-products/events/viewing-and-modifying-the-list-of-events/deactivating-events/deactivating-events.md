# Deactivating Events

In order to deactivate an Event,

1.  On the **Products** menu, click **Activities**.
2.  Open the required event. The Event page appears.
3.  Switch the **Active** toggle off. The event will be moved to archive.

![2024-11-12_14-36-40.png](/assets/2024-11-12_14-36-40.png)

1.  Click **Save**.

The deactivated events are not deleted permanently. They are moved to archive and can be restored. To view the list of archived events, in the table of self-operated events, switch **Active**toggle off:

![2024-11-12_23-25-40.png](/assets/2024-11-12_23-25-40.png)

To restore the archived events repeat\*\* Step 1\*\* and **Step 2**, then switch the Active toggle on and click **Save**.
