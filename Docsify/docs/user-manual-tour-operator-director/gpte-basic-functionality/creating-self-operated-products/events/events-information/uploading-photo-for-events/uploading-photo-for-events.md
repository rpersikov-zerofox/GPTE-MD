# Uploading photo for Events

You can demonstrate the event by showing it with the images. To add the images to the event, do the following.

## **Uploading images from your PC**

To upload an image from your PC,

1.  On the **Photo** tab, click at the **Select photos**field.

![2024-11-12_15-31-37.jpg](/assets/2024-11-12_15-31-37.jpg)

2.  Browse to the image you want to upload, and click **Open**.
3.  Select the respective image category from the drop-down list below the image.
4.  Click **Save**.
