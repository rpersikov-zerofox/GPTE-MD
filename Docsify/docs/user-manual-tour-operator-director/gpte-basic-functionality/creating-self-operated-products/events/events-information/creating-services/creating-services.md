# Creating Services

To specify the general parameters of the new event and create the constituent services,

1.  Open the profile of the required self-operated event.
2.  On the Information tab, **Services** sub-tab click **Create**. Service page appears:

![2024-11-12_15-24-15.jpg](/assets/2024-11-12_15-24-15.jpg)

![2024-11-12_15-24-25.jpg](/assets/2024-11-12_15-24-25.jpg)

3.  On the Service page, specify the following information:

- **Name**: enter the name of the service.
- **Type**: select the type of the event service.
- **Category**: select the service category. In the list previously created and stored in the event directory categories are available. If you do not see a suitable item in the list, please turn back to the Catalogue tab.
- **Description**: enter the service description.
- **Number of tourists**: specify the number of tourists for whom the service is available.

4.  Click **Save**. The service is added to the list of event services.
