# Creating a new event

To create a new event,

1.  On the **Products** menu, click **Activities**.
2.  On the Activities page, click **Create**→\*\* **choose** Event \*\*category. *Create new activity* window appears:

![2024-11-12_14-44-46.jpg](/assets/2024-11-12_14-44-46.jpg)

![2024-11-12_14-46-14.jpg](/assets/2024-11-12_14-46-14.jpg)

3.  *Create new activity* page specify the following information:

- **Recommended**- is implemented for own events. If to switch on this option on Back-Office, you can sort products by option "Recommended" on the results search page on the Website
- **Name**: enter the event name.
- **Product name for Supplier**: add a product name as a supplier calls it.\*\* \*\*The product name for the supplier is used in notifications to the supplier.
- **Supplier**: select the event service supplier.
- **Event type**: select the event type - concert, sport or other.
- **Type**: select the event type - either shared or private.
- **Default currency**: from the drop-down, select the currency to use for settlements with service supplier. The selected currency will also be used for configuring tariffs, price-lists, etc.
- **Country**: select the country where the event takes place.
- **City**: select the city where the event takes place.

After you have finished to fill in all the details click **Save**. Your event will be saved into the system. Open the created event product and navigate to **Description** tab and enter corresponding information:

- **Short description**: briefly describe the service. This description will be displayed on the search results page.
- **Description**: enter the service description. This description will be displayed in the window with the detailed description of the service.
- **Important information**: enter additional important details.

4.  Click **Save**.
