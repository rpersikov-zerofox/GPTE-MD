# Creating a new tour

To create a new tour,

1.  On the **Products** menu, click **Tours**.
2.  On the Tours page, click **Create**. *Create new tour* page appears:

![2024-11-13_09-47-45.png](/assets/2024-11-13_09-47-45.png)

3.  On the *Create new tour* page, specify the following information:

- **Name**: type the name of the tour.
- **Supplier**: select the tour service supplier.
- **Default currency**: select the currency to use for settlements with supplier. The selected currency will also be used for configuring tariffs, price-lists, setting penalties, etc.
- **Same board type**: select the check box in case you do not allow different board types for tourists of one room type.
- **Ending location**: specify one or more destination locations: \* Click **Add**. The Choose the city window appears:

![2024-11-13_09-48-05.jpg](/assets/2024-11-13_09-48-05.jpg)

- **Duration**: specify the tour duration - type the number of days the tour lasts for.

After you finished to fill in all the details click **Save**. Your tour will be saved into the system. Open the created tour product and navigate to **Description** tab → **General** sub-tab and enter corresponding information:

- **Short description**: enter a brief tour description. The description will be displayed on the Search results page.
- **Fill description**: enter a tour description. This description will be displayed in the window with the detailed description of the tour.
- **Important information**: enter additional important details.

After you finished to fill in all the descriptions click **Save**.

You can include day-by-day plan information into tour description navigating to **Description** tab → **Day-by-day plans** sub-tab and entering detailed description for every day of the tour (the quantity of fields depends on the days number indicated in **Duration** box when creating a tour):

![2024-11-13_10-02-45.jpg](/assets/2024-11-13_10-02-45.jpg)

To upload a picture for the tour from your PC, navigate to **Photo** tab:

- click at **Select photos**field, browse to the required picture, click **Open** and upload a picture;
- click **Save**.
