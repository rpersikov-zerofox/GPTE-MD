# Viewing/Editing Tours

To view or edit a tour,

1.  On the **Products**menu click **Tours**.
2.  In the table of tours click the required one.
3.  The Tour page appears:

![2024-11-13_13-11-57.jpg](/assets/2024-11-13_13-11-57.jpg)

4.  Go to the required tab and make necessary corrections.
5.  Click **Save**.
