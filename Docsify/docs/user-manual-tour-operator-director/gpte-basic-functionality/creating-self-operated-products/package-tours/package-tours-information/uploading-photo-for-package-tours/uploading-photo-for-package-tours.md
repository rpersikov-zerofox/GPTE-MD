# Uploading Photo for Package Tours

You can demonstrate the package tour itinerary by showing it with the images. To add the images to the description of your itinerary, go to **Photo**tab and do the following.

To upload an image from your PC,

1.  On the **Photo** tab, click at Select photos field.
2.  Browse to the image you want to upload, and click **Open**.
3.  Select the day from the from the drop-down list below the image.
4.  You can additionally specify the **image title** (enter text description for the image).
5.  If you want to show photos within the photo galleries in a specified order -- indicate the display order number.
6.  To display the uploaded image as a thumbnail on the hotel search results page, click the checkbox opposite the required image.
