# Setting Info

To create a new package tour,

1.  On the **Products** menu click **Package** **Tours**.
2.  On the Package Tours page, click **Create**. *Create new package tour* page appears:

![2024-11-14_09-37-56.jpg](/assets/2024-11-14_09-37-56.jpg)

3.  On the *Create new package tour* page, specify the following information:

- **Name**: type the name of a package tour.
- **Supplier**: select the service supplier. Here you can choose either your own company (if you organize the package tour by yourself) or the supplier, from whom you get this package tour product.
- **Default currency**: specify the currency to be used for package tour calculations.
- **Duration (days)**: type the numbers days which the package tour includes.
- **Starting location**: indicate a start point of package tour clicking **Add** button. *Choose the Country/City* pop-up appears. Select a county and a city, click **Save**:

![2024-11-14_09-48-12.png](/assets/2024-11-14_09-48-12.png)

- **Ending location**: indicate an end point of package tour by analogy with entering starting location.
- **Tags:**enter a tag for a package tour, which will define the conditions of product search and booking (ex. "public" tag → the product is available for search and booking for all customers).
- **Configuration**: select one of the options - either *Dynamically calculate selling prices based on package components* or *Define static prices for package*.
- **Internal notes**: enter additional notes for a package tour.

4.  Click **Save**.

To add descriptions for the created package tour, navigate to **Description** tab and specify the following information:

- **Short description:**enter a brief tour description. The description will be displayed on the Search results page.
- **Description:**enter a package tour description. This description will be displayed in the window with the detailed description of the package tour.
- **Included:**enter the list of services that will be included in the package tour.
- **Not included:**enter the list of services that will not be included in the package tour and will be paid additionally (the optional service).
- **Terms & conditions**: enter information on terms and conditions for a package tour.
