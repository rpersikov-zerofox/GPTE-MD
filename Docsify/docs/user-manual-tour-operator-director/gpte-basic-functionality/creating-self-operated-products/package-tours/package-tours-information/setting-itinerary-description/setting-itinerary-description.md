# Setting Itinerary description

After filling the Info tab you should specify the itinerary description offered for tourists.

1.  Go to the **Itinerary description**sub-tab.
2.  On the Itinerary description tab you can see the number of bars that are equal the package tour duration.
3.  Click each bar to expand the form and fill in the day itinerary.

![2024-11-14_10-20-32.jpg](/assets/2024-11-14_10-20-32.jpg)

4.  As soon as the required information is specified, click **Save**.
