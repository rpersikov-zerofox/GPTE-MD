# Package Tours Itinerary

To create new tour component

1.  Go to the **Itinerary**tab and click **Create**.
2.  *New tour component* window appears:

![2024-11-14_11-41-55.jpg](/assets/2024-11-14_11-41-55.jpg)

We extended services which can be added to Package Tours. Now it is possible to include new products "**cruises" and "cars" in Package Tour.**

## New hotel component

To create New hotel component,

1.  Go to the **Itinerary**tab, click **Create** and Choose **Hotel** check-box, click **Add**.
2.  *Create hotel component*page appears:

![2024-11-14_11-43-28.jpg](/assets/2024-11-14_11-43-28.jpg)

3.  Specify,

- **Entry code:** specify the component code.
- **Name:**enter the hotel name.
- **Day number**: choose which day this services is started from the drop-down list.
- **Include component as**: \* **Mandatory:**This service is included in the tour and cannot be removed. \* **Optional service:**This service is not included in the tour and is additionally offered during the booking.
- **City**: Select a city of package tour component(s).

For Package tours we added settings on several hotels in one city. Now it is possible to add the necessary number of hotels in one city (clicking **Multiple choice**at the Product field). Also you can use the filter "search by name" if there are many hotels on the list.

![2024-11-14_11-47-02.jpg](/assets/2024-11-14_11-47-02.jpg)

- **Product:**locate mouse pointer into the box and start typing. After you type 3 characters the system will display the list of self-operated hotels. The items on the list are arranged by the alphabet. If you do not see the required item in the list. type some more characters - it may appear later.
- **Number of nights:** choose how many nights the tourist will stay in this hotel from the drop-down list.
- **Tags**: Every new product has a "public" tag by default. This means that products with this tags will be offered via the tour. However, you can create additional tags. In this case, if a products contains at least one additional tag along with the "public" tag, the conditions of the additional tag are applied to them. *Also you can add tags and products will be not offered via this tour.*

4.  Click **Save**.

## **New flight component**

To create New Flight component,

1.  Go to the **Itinerary**tab, click **Create** and Choose **Flight** check-box, click **Add**.
2.  *Create flight component* page appears:

![2024-11-14_12-06-23.jpg](/assets/2024-11-14_12-06-23.jpg)

3.  Specify,

- **Entry code:** specify the component code.
- **Name:**enter the flight name.
- Select one of the options: **Oneway** or **Roundtrip**
- **Day number**: choose which day this services is started from the drop-down list.
- **Include component as**: \* **Mandatory:**This service is included in the tour and cannot be removed. \* **Optional service:**This service is not included in the tour and is additionally offered during the booking.
- **Product:**locate mouse pointer into the box and start typing. After you type 3 characters the system will display the list of self-operated charters. The items on the list are arranged by the alphabet. If you do not see the required item in the list. type some more characters - it may appear later.
- **Departure** and **Destination** points.
- **Tags**: Every new product has a "public" tag by default. This means that products with this tags will be offered via the tour. However, you can create additional tags. In this case, if a products contains at least one additional tag along with the "public" tag, the conditions of the additional tag are applied to them. *Also you can add tags and products will be not offered via this tour.*

4.  Click **Save**.

The whole itinerary list will be in the **Itinerary** tab:

![2024-11-14_12-12-08.jpg](/assets/2024-11-14_12-12-08.jpg)
