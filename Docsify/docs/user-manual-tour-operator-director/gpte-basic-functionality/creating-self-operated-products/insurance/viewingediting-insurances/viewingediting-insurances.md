# Viewing/Editing Insurances

To view or edit an insurance,

1.  On the **Products** menu, click **Insurance**.
2.  In the table of insurances, click the required one.
3.  The Insurance page appears:

![2024-11-13_17-30-58.jpg](/assets/2024-11-13_17-30-58.jpg)

4.  Go to the required tab and make necessary corrections.
5.  Click **Save**.
