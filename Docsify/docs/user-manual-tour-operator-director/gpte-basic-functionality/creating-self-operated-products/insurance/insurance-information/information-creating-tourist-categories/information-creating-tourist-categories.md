# Information: Creating Tourist Categories

You may differentiate prices for self-operated products depending on the category of tourists who buy them. The Adult tourist category is created in the system by default.

To create a new tourist category,

1.  On the **Products** menu, click **Insurance**.
2.  On the Information tab, **Guests categories**sub-tab, click **Create**. *Create tourist* page appears:

![2024-11-13_16-09-14.jpg](/assets/2024-11-13_16-09-14.jpg)

3.  On the *Create tourist* page, specify the following information: 1. **Name:** type the name of the category. 2. **Category:** select the category type - whether it refers to adults or children. 3. **Default:** generally the Adult tourist category is created automatically and set as default. However you can change the default category selecting the Default check box. 4. **Age:** specify the age range acceptable for the category. *Please pay attention that in case you create several tourist categories (e.g. infant, child), the age ranges should not overlap. Thus, in case age range for Infant is 0 to 2, the age range for Child should start with 3 years old.*
4.  **Description:** describe the tourist category.
5.  Click **Save**. The new tourist category is added to the list of available categories.
