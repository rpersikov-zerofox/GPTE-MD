# Charter Availability

With the seat allotments, you can indicate the number of seats that are currently available and specify the dates of service booking.

**To set seat allotments,**

1.  Select the necessary operation from the list (**This list is currently available via administration panel** ): 1. **Set up allotment:** set up a number of allotments (guaranteed quotas) allocated to you by the supplier. 2. **Terminate allotment:** cease sales for a certain period. For instance, if the supplier recalls the allotment. 3. **Block out:** set up periods when the service is not available for booking, for instance, during fairs and exhibitions. 4. **Set release:** release is the number of days after the booking when the supplier does not guarantee the allotment and therefore confirmation of the service available from the supplier is required. Example: - Suppose today is January 1. - You have an allotment for 10 units (10 seats on a charter flight) - The release lasts for 7 days according to the agreement with a supplier. - This means that you can book up to 10 services a day, starting from January - The bookings that are made from January 1 to January 7 are not confirmed automatically and are processed "upon request". 5. **Set by default:** resets the number of allotments to the initial value (0, by default means, that the hotel is available upon request only).

![2024-11-11_12-53-45.jpg](/assets/2024-11-11_12-53-45.jpg)

2.  Set up operation parameters. You can select the following parameters: 1. **Period** (from-to): the period of time when the conditions are applied. 2. **Days of the week:** select All to choose the allotment conditions for the whole week. If you need to limit the availability of the service, for instance, set allotments for week-ends only, select the respective checkboxes manually. 3. **Sub-allotment:** Creating sub-allotments allows you to specify different sales conditions within the allotment group provided by the supplier. Created sub-allotments are available in the Sub Allotment drop-down.

![image-20200922-110109.png](/assets/image-20200922-110109.png)

3.  Specify the number of allocated units in the Quantity group. When limiting the number of allocated units, select one of the following options: 1. **On request:** during the booking, you should make an additional request about the availability of the service from the supplier. Instant confirmation of the service is unavailable. 2. **Unlimited:** the number of services that can be booked is unlimited. This service is confirmed immediately. 3. **Limited:** the number of instantly confirmed services is limited. Once the allotment provided is exhausted, you can only make new bookings if the Allow Overbooking checkbox is selected. In this case, the services are offered "upon request", this means you have to contact the service supplier to check if the booking can be confirmed, if not, further bookings will be impossible.

Allotment management can be illustrated with the following example.

**Full functionality, presented in the example, is currently available via administration panel.**

Suppose you have an agreement with the supplier on 25 single services of the Comfort category to be booked from June 1 to June 30 and all are offered upon request.

To set this number of guaranteed services in the system:

1.  Click Create Allotment (*see Group 1 in the figure below*).
2.  Set the time from June 1 to 30 (*Group 2*).
3.  Select the required allotment, Flight number/Class, Departure time (*Group 3*).
4.  In the Quantity group, click Limited, and specify the number of quantity that you can offer (*Group 4*).
5.  Click Update.

**To set Blockout,**

1.  Click Blockout (Group 1);
2.  Select sub allotment, category, Flight number/Class and Departure time for which you set Blockout (Group 2);
3.  Click Set Blockout (Group 3);
4.  To reset Blockout click Reset Blockout (Group 4). This function permits to cancel all previous settings on block-out with saving all other allotments.
