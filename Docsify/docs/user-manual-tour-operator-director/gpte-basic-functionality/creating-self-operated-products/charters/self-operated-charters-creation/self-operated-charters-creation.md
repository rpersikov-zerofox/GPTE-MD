# Self-operated charters creation

Self-operated charters are created according to the common scheme. The process begins with choosing the necessary category and entering general information about the charter.

## Creating a New Charter

1.  On the Navigation bar click Products → Flights.
2.  On the Flights page, click Create. 'Create new charter' window appears:

![2024-10-29_10-57-57.jpg](/assets/2024-10-29_10-57-57.jpg)

3.  Specify the following information: 1. **Name:** locate mouse pointer into the bar and enter the name of the charter. 2. **Product name for supplier**: add a charter name as a supplier calls it.\*\* **The product name for the supplier is used in notifications to the supplier. 3.**Supplier:\*\* from the drop-down, select the charter supplier. In the drop-down only direct contracted suppliers are available. 4. **Default currency:** from the drop-down, select the currency to use for payments with the supplier. 5. **Airline:** from the Airline drop-down, select the name of an airline. 6. **Departure:** enter charter departure airport. *To add a departure point, locate the mouse pointer into the box, and start typing, the system automatically suggests the available points. Alternatively, you can select the departure point from the list, specifying first a country, then a city, and an airport.* 7. **Arrival:** enter charter arrival airport.
4.  Click Save.

**Creating Categories of Travelers**

You may differentiate prices for self-operated products depending on the category of tourists who buy them. For instance, adjust the allocation price rate depending on the age of a tourist. For example, the number of hotels and airlines provides discounts for children. The Adult tourist category is created in the system by default.

**To create a new traveler category**,

1.  Open the profile of the required self-operated product.
2.  On the Information tab, in the **Travelers categories** sub-tab, click Create. 'Create tourist' window appears:

![2024-10-29_11-03-11.jpg](/assets/2024-10-29_11-03-11.jpg)

1.  In the Create tourist window, specify the following information:

**a. Name:** locate mouse pointer into the box and type the name of the category.

**b. Category:** from the drop-down, select the category type - adults or children.

**c. Default:** generally the Adult tourist category is created automatically and set as default. However, you can change the default category selecting the Default checkbox.

**d. Age:** specify the age range acceptable for the current category.

:   *Please pay attention that in case you create several tourist categories (e.g. infant, child), the age ranges should not overlap. Thus, in case the age range for the Infant is 0 to 2, the age range for Child should start with 3 years old.*

**e. Description:** locate the mouse pointer into the text field and describe the category you are creating.

1.  Click Save. The new tourist category is added to the list of available categories.

## Creating Catalogue of Charters

For every created charted description, you should create the catalogue of flight numbers. For each flight, you should indicate its number, available classes of service, and direction (outbound or inbound flight).

**To create a catalogue of flight numbers,**

1.  Open the contract of a required charter.
2.  On the Information tab, in the **Flight number** sub-tab, click Create. 'Create flight number' window appears:

![2024-10-29_11-08-38.jpg](/assets/2024-10-29_11-08-38.jpg)

1.  In the Create flight number window, specify the following information: 1. **Name:** locate mouse pointer into the box and type the flight number. *When adding a flight number to a catalogue, flight numbers should be specified only numerically, without letter codes. When a flight is booked, the letter codes are added to the flight* *number automatically.* 2. **Description for internal use:**the box is used for the convenient management of charters. The information you enter is not displayed on the Search results page and is used for inner management only. 3. **Service classes:** select the service classes available for the passengers of the charter. 4. **Flight direction:** click a button of your choice to specify whether the flight is out- or inbound.
2.  Click Save.

## Setting Schedule

For each created flight number, you need to specify the time of the flight in the schedule.

**To add a new itinerary to a charter contract**,

1.  Open the profile of the required charter.
2.  On the Information tab, in the **Timetable** sub-tab, click Create. 'Create schedule' window appears:

![2024-10-29_11-10-40.jpg](/assets/2024-10-29_11-10-40.jpg)

1.  In the Create schedule window, specify the following information: 1. **Flight number:** from the drop-down, select the flight number. In the list the previously created flight numbers are available. 2. **Departure time:** locate mouse pointer into the box and enter the time of the departure. The required format is indicated above the box. 3. **Arrival time:** locate mouse pointer into the box and enter the time of arrival in the required format. 4. **Duration:** specify the flight duration.
2.  Click Save.
