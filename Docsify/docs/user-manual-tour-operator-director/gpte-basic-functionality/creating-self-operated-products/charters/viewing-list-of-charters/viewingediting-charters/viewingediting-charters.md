# Viewing/Editing Charters

**To view or edit a charter**,

1.  Go to **Products** and click Flights.
2.  In the table of charters, click the required one.
3.  The Flight page appears:

![2024-11-11_13-37-45.jpg](/assets/2024-11-11_13-37-45.jpg)

4.  Go to the required tab and make the necessary corrections.
5.  Click Save.
