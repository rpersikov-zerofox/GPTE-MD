# Viewing/Editing Visas

To view or edit a visa,

1.  On the **Products** menu, click **Visa**.
2.  In the table of visas, click the required one.
3.  The Visa page appears:

![2024-11-13_14-58-37.jpg](/assets/2024-11-13_14-58-37.jpg)

4.  Go to the required tab and make necessary corrections.
5.  Click **Save**.
