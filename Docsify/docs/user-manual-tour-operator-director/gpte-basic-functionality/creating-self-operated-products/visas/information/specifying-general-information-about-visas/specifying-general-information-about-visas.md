# Specifying General Information about Visas

To create a new self-operated visa,

1.  Click **Products** → **Visa**tab.
2.  On the Visas page click **Create**. *Create new visa* page appears:

![2024-11-13_13-20-46.jpg](/assets/2024-11-13_13-20-46.jpg)

3.  On the *Create new visa* page, specify the following information: 1. **Name:** type the name of the visa. 2. **Supplier:** select the visa service supplier. 3. **Default currency:** select the currency to use for settlements with supplier. The selected currency will also be used for configuring tariffs, price-lists, etc. 4. **The documents are submitted by tourists in person at the embassy:** select the check box to indicate that the tourists must submit the documents in person at the embassy. 5. **Country of destination:** select the destination country from the drop-down. 6. **Applicant\'s country of residence:** in case a supplier places certain restrictions on the applicant\'s citizenship, it may be needed to indicate the applicant\'s country of residence. In order to restrict the citizenship of applicants, 1. Select **Select from the list**option. The additional form appears. 2. Click **Add**. *Applicants country of residence* window appears, select a country and click Save. The location is saved in the form:

![2024-11-13_13-24-29.png](/assets/2024-11-13_13-24-29.png)

4.  Click **Save**.
