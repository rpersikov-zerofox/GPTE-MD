# Configuring Terms of Order

**This functionality is currently available via administration panel.**

For obtaining visa services, you can specify the set of additional fields required for application. To add the terms of ordering,

1.  Open the required visa product.
2.  On the Information tab, in the Terms of ordering group, click **Edit**.
3.  Select the check boxes of your choice:

![image-20201012-093650.jpg](/assets/image-20201012-093650.jpg)

4.  Click **Save**. The selected fields are now displayed on the booking form, in the Information about applicants group.
