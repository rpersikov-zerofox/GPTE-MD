# Creating Visa Services

For every self-operated visa service, you should specify the type of visa and the number of entries it allows. The specified information is stored in one directory on the Services tab.

Thus to create a new visa category,

1.  On the **Products** menu click **Visa**tab.
2.  Open the required visa.
3.  On the Information tab → **Services** sub-tab, click **Create**. *Create service* page appears:

![2024-11-13_13-39-27.jpg](/assets/2024-11-13_13-39-27.jpg)

4.  On the *Create service* page, specify the following information: 1. **Name:** locate mouse pointer into the box and type the name of the service. 2. **Type:** from the drop-down select the type of the visa, e.g. tourist, business, etc. 3. **Category:** from the drop-down select the entry type, e.g. single, double, multiple. 4. **Description:** locate mouse pointer into the text field and describe the type of service.
5.  Click **Save**. The new service type is created and added to the directory of visa services.
