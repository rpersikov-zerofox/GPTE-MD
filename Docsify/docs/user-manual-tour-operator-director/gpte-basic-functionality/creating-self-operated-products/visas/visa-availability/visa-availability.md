# Visa Availability

**This functionality is currently available via administration panel.**

On the Availability tab, you can manage the availability of visa services, specifically:

- set blockout
- set by default.

![image-20201012-134740.png](/assets/image-20201012-134740.png)

By default, the number of allotments for visas is unlimited. However in case you need to stop visa distribution, you can set blockout - set up periods when the service is not available for booking.

**To set blockout,**

1.  Click\*\* Blockout\*\*.
2.  Set the required time span when the service is not available. For the time span, specify the period of time and the days of the week when the conditions are applied. If you need to set special conditions on week-ends, select the required days manually.
3.  Select visa category and services for which you set blockout.
4.  Click **Set blockout**.

![image-20201012-134914.png](/assets/image-20201012-134914.png)

Another option you can configure is to set visa availability by default. As it was previously mentioned unlike for other self-operated services, for visas the number of allotments is not restricted. So if you set the allotments to initial value, the number of available allotments is unlimited.

**To set the allotments by default,**

1.  Click **Set by default**.
2.  Set the required time span for which the default configurations will be applied. For the time span, specify the period of time and the days of the week when the conditions are applied.
3.  Select visa category and services for which you set default configurations.
4.  Click **Update**.

![image-20201012-135228.png](/assets/image-20201012-135228.png)

The number of allotments is reset to the initial value, which is seen on the diagram and in a table report:
