# Managing Company Users

Each employee who needs access to the platform requires a unique user account. User accounts control system access and define what actions each person can perform based on their assigned role.

## User Roles and Permissions

User roles determine access levels within the system:

- **Director** and **Supervisor** roles have full system access with no restrictions
- **Agent** roles can be configured with limited permissions (for example, booking services only)
- Custom role permissions can be configured to match your business needs

## User Account Basics

The system supports unlimited user accounts. Each user receives:

- A unique username for system login
- A secure password for authentication
- An assigned role that determines their permissions and capabilities
