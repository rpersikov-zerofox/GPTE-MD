# Specifying Company Profile Settings

Configure system preferences, localization, API access, and platform customization through Company Profile Settings. These settings control how your company uses the GP Travel Enterprise platform.

## Overview

Company Profile Settings allow you to:

- Customize user interface appearance
- Configure localization and language preferences
- Set up API access for integrations
- Define company-specific URLs
- Upload branding elements (logos, icons)
- Configure data import and export
- Set location preferences

## Access Company Profile Settings

Navigate to **My Company** > **My Company** > **Settings** tab

## Common Configuration Tasks

### Initial Setup

When first configuring your company profile:

1. **Set Localization** - Choose language, currency, and date formats
2. **Configure UI** - Upload logos and set brand colors
3. **Set Locations** - Define default cities and regions
4. **Generate API Key** - If using integrations
5. **Configure URL** - Set up custom domain (optional)

### Regular Maintenance

Periodically review and update:

- API keys and security credentials
- Branding and logo images
- Localization settings for new markets
- Data import/export configurations

## Settings Impact

Changes to Company Profile Settings affect:

- **All Users** - UI and localization settings apply company-wide
- **System Behavior** - API and integration settings control data flow
- **Booking Process** - Location preferences influence search defaults
- **Reports** - Currency and format settings affect reporting

**Important:** Some settings require system administrator privileges. Changes may require users to log out and log back in to take effect.

## Best Practices

### Security

- **Protect API Keys** - Store securely, don't share publicly
- **Regular Reviews** - Audit API access periodically
- **Access Control** - Limit who can modify settings

### User Experience

- **Consistent Branding** - Use high-quality logos and images
- **Clear Localization** - Set formats appropriate for your market
- **Test Changes** - Verify settings before applying company-wide

### Integration

- **Document API Keys** - Maintain records of integration configurations
- **Test Imports/Exports** - Verify data transfers before production use
- **Backup Settings** - Keep records of configuration changes

## Troubleshooting

**API Integration Not Working:**
- Verify API key is current and valid
- Check integration permissions
- Review API documentation for format requirements

**UI Changes Not Appearing:**
- Clear browser cache
- Log out and log back in
- Verify settings were saved correctly

**Localization Issues:**
- Check language packs are installed
- Verify regional settings match your requirements
- Review currency conversion rates
