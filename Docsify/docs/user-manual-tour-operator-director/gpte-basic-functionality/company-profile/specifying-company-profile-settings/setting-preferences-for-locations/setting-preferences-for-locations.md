# Setting Preferences for Locations

**This functionality is currently available via administration panel.**

On the Search form, there are several possible ways to display cities and regions. You can configure the display of the locations and the default search method.

To adjust the preferences for locations,

1.  On the Navigation bar, point to **Company profile** and click **Settings**.
2.  On the UI tab, click **Preferences for locations** to expand the bar.
3.  In the **Preferences for locations** group, specify the following:

Specify the look of the search form for destinations: a text box or a drop-down. When the search form is displayed as a text box, after you type a character the system will display the list of suggestions containing the defined characters. The output for the respective options will look as follows:

Specify whether to display the cities and regions in separate blocks or together. The output for the respective options will look as follows:

![image-20200917-173555.jpg](/assets/image-20200917-173555.jpg)

Specify the way the destinations are displayed in drop-downs. The output for the respective options will look as follows:

![image-20200917-173633.jpg](/assets/image-20200917-173633.jpg)

Specify the distance to search for the airports in case there is no airport in the region under search. Then in case there are no airports in the destination you search for, the results will display the airports located nearby at a specified distance.

4.  Click **Save**.
