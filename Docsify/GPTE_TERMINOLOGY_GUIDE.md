# GPTE Documentation Terminology Guide

Quick reference for consistent terminology across GP Travel Enterprise documentation.

---

## Product & System Terms

| Preferred Term | Avoid | Notes |
|----------------|-------|-------|
| GP Travel Enterprise | GPTE system, the platform | Use full name on first mention, then "the platform" or "the system" |
| self-operated | selfoperated, own products | Hyphenated compound adjective |
| third-party supplier | external supplier | For non-self-operated products |
| accommodation | hotels, lodging | Umbrella term; use "hotel" when specific |

## User Interface Elements

| Preferred Term | Avoid | Example Usage |
|----------------|-------|---------------|
| click | click on, press | "Click **Save**" |
| select | choose, pick | "Select a date from the calendar" |
| enter | input, type in | "Enter your company name" |
| navigation bar | navbar, menu bar | "In the navigation bar, click **Reports**" |

## User Actions

| Preferred Term | Avoid | Context |
|----------------|-------|---------|
| generate a report | obtain a report, get a report | Reports and analytics |
| view | see, look at, obtain | Passive viewing |
| access | get access to, obtain | System permissions |
| create | make, add | New records |
| modify | change, edit, update | Existing records |
| configure | set up, setup (noun only) | System settings |

## User Roles & Accounts

| Preferred Term | Avoid | Notes |
|----------------|-------|-------|
| user account | user profile, login | System access credentials |
| user role | permission level, access level | Director, Supervisor, Agent |
| company profile | company information, company data | Business entity details |

## Travel Industry Terms

| Preferred Term | Avoid | Notes |
|----------------|-------|-------|
| traveler | tourist, passenger, guest | Individual taking a trip (US spelling) |
| reservation | booking (when ambiguous) | Complete travel arrangement |
| booking | reservation (when specific) | Act of reserving |

| PNR | passenger record | Passenger Name Record |

## Booking Types

## Document Sections

## Common Phrase Improvements

### Awkward → Natural

| Awkward (Avoid) | Natural (Use) |
|-----------------|---------------|
| allow to obtain | let you view |
| decide on the type | select the type |
| you can see the lists of | you can view |
| in order to | to |
| by using | with / using |
| the platform provides information about | the platform displays |
| at this stage | in this step |
| if you are not satisfied with | if the results don't meet your needs |

### Passive → Active

| Passive (Avoid) | Active (Use) |
|-----------------|-------------|
| The report is generated by the system | The system generates the report |
| Users are assigned with roles | Assign roles to users |
| Information is saved in the system | The system saves the information |
| Reservations can be modified | You can modify reservations |

## Capitalization Rules

### Always Capitalize

- Product names: GP Travel Enterprise
- Module names: Search & Book, Analytics, Reservations
- UI elements when referenced: **Save** button, **Reports** menu
- Role names: Director, Supervisor, Agent

### Don't Capitalize

- Generic terms: user, company, reservation, invoice
- Features: search, booking, reporting (unless part of module name)
- Document types: voucher, contract, price list

---

## Date and Number Formats

### Dates
- Use: January 15, 2024 (long form in text)
- Use: 2024-01-15 (ISO format in tables/data)
- Avoid: 01/15/2024, 15/01/2024

### Numbers
- Spell out: one through nine
- Use numerals: 10 and above
- Exception: Use numerals in UI instructions ("Click 3 times")

### Currency
- Use: $100 USD, €50 EUR
- Avoid: USD $100, $100 dollars

## Link Text Best Practices

### Good Link Text
- "View the [User Management Guide](link)"
- "[Create a new user account](link)"
- "Learn more about [pricing calculation](link)"

### Avoid
- "Click [here](link) for more information"
- "[Link](link) to documentation"
- "Read more [→](link)"

## Voice and Tone Guidelines

### Use Second Person
- ✓ "You can create unlimited users"
- ✗ "Users can be created without limits"

### Use Active Voice
- ✓ "The system generates the report"
- ✗ "The report is generated"

### Use Present Tense
- ✓ "The page displays your reservations"
- ✗ "The page will display your reservations"

### Be Direct and Concise
- ✓ "Click **Save**"
- ✗ "You should now click the Save button"

---

## Special Cases

### Self-Operated Products
- First mention: "self-operated products (products you own and operate)"
- Subsequent: "self-operated products"
- Related: self-operated hotels, self-operated tours

### Company vs Organization
- Use "company" for GP Travel Enterprise business customers
- Avoid "organization" unless specifically referring to non-commercial entities

### System vs Platform
- Both acceptable as variations
- Prefer "platform" for first mention
- Use "system" for brevity in subsequent references
